# Nexa Mobile Report v0.1.0

## Scope

`v0.1.0` is the first public academic release of the Nexa Mobile Report for
course 1ACC0238, *Aplicaciones para Dispositivos Móviles*. It presents Nexa's
product and research framing, requirements and software solution design,
UI/UX design, and Sprint 1 planning.

The report is not a claim that a Mobile application, device build, deployment,
or user-study result has been completed.

## Release identity

- Release branch: `release/v0.1.0`
- Integrated `develop` baseline: `3713c77b913a36a9a9115ddc80d10240894f62c9`
- Immutable release tag: `v0.1.0`

The tag is created only after release verification and identifies the exact
published release commit.

## Included work

- Canonical Chapter I–IV report structure with temporary overview artifacts
  removed.
- Chapter II Needfinding with User Personas, User Task Matrix, User Journey
  Mapping, Empathy Mapping, and Ubiquitous Language.
- Lean UX, Impact Mapping with selected full User Story descriptions, a
  97-item Product Backlog, 11 accepted Bounded Contexts, C4 views, and Tactical
  DDD coverage.
- Sprint 1 planning: 20 tasks, 98 planned hours, and explicit To Do status.
- AV1 Student Outcome 7 evidence, two SMART objectives per team member, and
  public closing sections.

## Verification

- Canonical report structure and heading hierarchy
- Internal Markdown links and local assets
- Story, backlog, DDD, C4, and Sprint Backlog integrity
- Bibliography citation integrity
- `git diff --check`
- Native PDF export and visual review

## Known limitations

- Direct needfinding interviews and their consented records are not included in
  this public release.
- No Mobile runtime, device, deployment, or user-validation result is claimed.
