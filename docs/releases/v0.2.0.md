# Nexa Mobile Report v0.2.0

## Scope

`v0.2.0` is the integrated AV1 academic release of the Nexa Mobile Report for
course 1ACC0238, *Aplicaciones para Dispositivos Móviles*. It consolidates the
front matter and Chapters I–IV from the six authorized feature branches and
preserves the distinction between verified report evidence and future work.

The report is not a claim that a Mobile application, device build, deployment,
interview validation, or UXPressia export has been completed.

- Integrated feature baseline on `develop`: `c8f6697dd26e8b28a42f95206a5dd90d022e7edc`

The tag identifies the exact release commit after release verification.

## Included work

- Front matter aligned with Statement V4.0 and ABET Student Outcome 7.
- Chapter I Lean UX Canvas and research framing with explicit provisional
  evidence boundaries.
- Chapter II needfinding, 97-item backlog, UXPressia-ready source, eleven

- Chapter III persona-to-information-architecture-to-wireflow traceability with

- Chapter IV Jira-ready Sprint Planning for four coherent increments, SCM
