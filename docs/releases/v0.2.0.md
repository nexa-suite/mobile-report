# Nexa Mobile Report v0.2.0

## Scope

`v0.2.0` is an integrated pre-AV1 academic release of the Nexa Mobile Report
for course 1ACC0238, *Aplicaciones para Dispositivos Móviles*. It consolidates
the front matter and Chapters I–IV from six feature branches and preserves the
distinction between verified report evidence and future work.

The report is not a claim that a Mobile application, device build, deployment,
interview validation, or UXPressia export has been completed.

## Release identity

- Integrated feature baseline on `develop`: `c8f6697dd26e8b28a42f95206a5dd90d022e7edc`
- Release branch: `develop`

The tag identifies the exact release commit after release verification.

## Included work

- Front matter aligned with the current course statement and ABET Student
  Outcome 7.
- Chapter I Lean UX Canvas and research framing with explicit provisional
  evidence boundaries.
- Chapter II needfinding, 97-item backlog, research artifacts for possible
  external transfer, eleven Bounded Contexts, Structurizr-native C4 evidence,
  and DDD traceability.

  future prototype evidence classified `NOT YET DUE`.
- Chapter IV Sprint Planning for four coherent increments, repository
  documentation, and future implementation/deployment evidence classified
  honestly.
- Integrated conclusions, domain glossary, bibliography, and annex evidence.
