# Nexa Mobile Report v0.3.0

## Scope

`v0.3.0` is a pre-AV1 academic hardening release of the Nexa Mobile Report
for course 1ACC0238, *Aplicaciones para Dispositivos Móviles*. It improves
research, planning, domain, visual, and bibliography consistency while
preserving the distinction between report design and verified evidence.

The report is not a claim that a Mobile application, device build, deployment,
completed interview sample, Product Board, or user validation has been
completed.

## Release identity

- Integrated report baseline on `develop`
- Release branch: `develop`
- Immutable release tag: `v0.3.0`

The tag identifies the exact release commit after release verification.

## Included work

- Explicit As-Is Scenario Mapping for Warehouse & Dispatch Operations, Driver
  Delivery Execution, and B2B Buyers, with their actual evidence boundaries.
- Interview-design clarification for voluntary residence and activity districts,
  plus research-to-story traceability that preserves Buyer evidence as `n = 2`.
- Reconciled functional-story catalog: 73 Mobile stories plus 6 Landing Page
  stories, with the four-Sprint academic commitment kept separate.
- Rendered Domain Storytelling assets and aligned DDD labels, including the
  Commercial Commitment, Inventory Reservation, Warehouse Backing, and
  Physical Allocation sequence.
- Updated academic language, visual captions, current-scope diagram labels,
  bibliography classification links, and exposition-video annex structure.

## Verification

- All eleven Bounded Contexts were checked for Markdown, tactical sources,
  C4 evidence, domain/database assets, XML validity, and current terminology.
- Relative links, SVG/XML assets, PlantUML sources, Mermaid render assets,
  shell syntax, report counts, and signed commits were checked before release.
- The report PDF was exported natively; a local cover preview was rendered for
  visual review.

## Known external evidence

- The required interview sample remains incomplete: Warehouse/Dispatch and
  Driver have no direct valid interviews; B2B Buyers has two documented
  interviews and still requires 3–5 per segment.
- The final Impact Mapping artifact remains outside this release.
- Final Jira/Product Board visual evidence remains outside this release.
- Videos de Exposiciones remains pending until an authorized source is
  available.
