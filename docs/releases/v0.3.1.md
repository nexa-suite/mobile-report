# Nexa Mobile Report v0.3.1

## Scope

`v0.3.1` reconciles the report planning baseline after the published
`v0.3.0` tag. It preserves the existing Chapter II commit history and makes
the current Product Backlog and the four Sprint plans internally consistent.

## Release identity

- Integrated report baseline on `develop`
- Release branch: `develop`
- Immutable release tag: `v0.3.1`

## Included work

- One Product Backlog with 97 elements: 79 functional, 12 technical, and 6
  Spike items, totalling 426 story points.
- Every element is assigned exactly once to one of four academic Sprints:
  Sprint 1 (5 / 18 SP), Sprint 2 (34 / 135 SP), Sprint 3 (31 / 134 SP), and
  Sprint 4 (27 / 139 SP).
- Sprint 1 remains a small initial access-and-Warehouse increment. Landing
  Page work is scheduled in Sprint 2.
- Chapter IV Sprint Planning and Sprint Backlog documents use the same
  allocation and totals as Chapter II.

## Verification

- Checked unique identifiers, type distribution, Sprint allocation, and story
  point totals in the Product Backlog.
- Checked Markdown whitespace, report links, signing, and release refs before
  publication.

## Evidence boundaries

- This release does not claim a Mobile implementation, device build,
  deployment, user validation, or interview findings beyond their documented
  sources.
- Outstanding external evidence remains documented where its genuine source is
  not available.
