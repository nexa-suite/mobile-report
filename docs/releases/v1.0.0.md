# Nexa Mobile Report v1.0.0

**AV1 Stable Baseline**

## Scope

`v1.0.0` establishes the first stable academic baseline of the Nexa Mobile
Report for AV1.

## Included scope

- Integrated AV1 report.
- Completed 9/9 formative Needfinding interviews.
- Lean UX and Needfinding artifacts.
- Requirements and Product Backlog.
- Impact Mapping.
- Strategic DDD and Tactical DDD.
- C4, UML and database design.
- Collaboration and SCM evidence.
- ABET Student Outcome evidence.

## Preserved invariants

- Product Backlog: 97 PBIs / 426 SP.
- Research: 9/9 interviews, three per segment.
- Eleven accepted Bounded Contexts.
- Four academic Sprints.

## Evidence boundary

This release stabilizes the **academic report baseline**. It does not declare a
completed Nexa Mobile product, production readiness, production deployment,
implementation of all backlog items, validation of all future hypotheses, or
completion of later course milestones.
