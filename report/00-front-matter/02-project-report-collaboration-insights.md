## Evidencia de colaboración

| Evidencia solicitada por la rúbrica | Estado | Tratamiento |
| :--- | :--- | :--- |
| URL público, ramas y PR | Verificado al corte | Enlaces reproducibles y manifest de fuentes |
| Captura de analíticos de GitHub | No evidenciada | Se incorporará sólo cuando exista una captura fechada y revisada |
| Participación individual por entrega | Parcial | Se respalda con commits reales, Performance Report y sustentación individual |
| Revisión académica | No evidenciada | No se atribuye aprobación a integrantes ni al docente |

Las capturas se incorporarán únicamente cuando el equipo las produzca y revise.
El historial de una fuente histórica no se presenta como colaboración de esta
entrega sin una correspondencia comprobada.
