# Project Report Collaboration Insights

## Repositorio y flujo

| Campo | Valor |
| :--- | :--- |
| Repositorio público del informe | [nexa-suite/mobile-report](https://github.com/nexa-suite/mobile-report) |
| Flujo de ramas | `main` ← `develop` ← ramas `chapter-0X` y `feature/*` |
| Convención de commits | Conventional Commits 1.0.0 |
| Corte local registrado | [`live-baseline.md`](../../delivery-checklists/live-baseline.md) |

El repositorio usa Markdown modular y conserva una rama por capítulo para
integración progresiva. Las ramas de funcionalidad deben tener alcance acotado,
revisión y trazabilidad hacia una persona que pueda explicar el cambio.

## Evidencia de colaboración

| Evidencia solicitada por la rúbrica | Estado | Registro requerido |
| :--- | :--- | :--- |
| Captura del repositorio y ramas | Pendiente | Captura con fecha y URL visible |
| Captura del historial de commits | Pendiente | Captura que permita identificar autoría y mensaje |
| Participación individual por entrega | Pendiente | Performance Report y defensa individual |
| Revisión de ownership antes del commit | En preparación | Checkpoint humano con propietario, archivos, fuente y validación |

Las capturas se incorporarán únicamente cuando el equipo las produzca y revise.
El historial de una fuente histórica no se presenta como colaboración de esta
entrega sin una correspondencia comprobada.
