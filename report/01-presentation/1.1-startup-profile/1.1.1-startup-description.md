# Capítulo 1: Introducción

## 1.1 Startup Profile

**Nexa-team** es una startup de base tecnológica enfocada en el desarrollo de
soluciones digitales para optimizar la coordinación comercial y operativa de
empresas importadoras, distribuidoras y mayoristas que trabajan con pedidos B2B.
Su producto principal, Nexa, busca ordenar el ciclo que conecta la intención de
compra del cliente con la disponibilidad, la preparación, el despacho y la
entrega del pedido. La cadena de frío representa una especialización relevante
del dominio, aunque la propuesta no se limita exclusivamente a empresas de
productos refrigerados o congelados.

El origen de la startup se relaciona con una oportunidad de digitalización
presente en operaciones B2B donde la información comercial y operativa suele
fragmentarse entre conversaciones, llamadas, audios, hojas de cálculo y
herramientas que no comparten el mismo contexto. Esta fragmentación puede
generar doble digitación, validaciones manuales, incertidumbre sobre la
disponibilidad real de los productos y dificultades para conservar la
trazabilidad de las decisiones tomadas durante el pedido y la entrega.

Frente a este contexto, Nexa se concibe como una propuesta especializada para
articular la intención de compra del cliente comercial con la ejecución del
pedido por parte de la empresa proveedora. La solución no busca reemplazar de
inmediato todos los sistemas administrativos, contables o logísticos de una
organización, sino establecer una fuente de coordinación clara para el flujo
comercial-operativo que conecta catálogo, solicitudes, compromisos, inventario,
despacho y evidencias de entrega.

El modelo de negocio de Nexa-team se plantea como **Software as a Service
(SaaS)** B2B y multi-tenant. Esta modalidad permite ofrecer una solución de
adopción progresiva para empresas que necesitan mejorar sus operaciones sin
desarrollar desde cero una plataforma propia. Cada empresa contratante debe
operar con información, usuarios, relaciones comerciales, productos, pedidos,
documentos y reglas de acceso aislados de los demás tenants, manteniendo una
base común de capacidades y lenguaje de negocio.

La propuesta se proyecta sobre un ecosistema de superficies complementarias:
Landing Page para comunicar el valor del producto, Internal Web Platform para
la administración y las operaciones internas, Buyer Portal Web para la
relación de compra autorizada, Nexa Operations Mobile para tareas operativas y
Nexa Buyer Mobile para las acciones frecuentes del comprador B2B. Las
experiencias web y móviles comparten el mismo dominio y las mismas reglas de
negocio; las aplicaciones móviles amplían el acceso operativo y no constituyen
productos o bounded contexts independientes.

En términos estratégicos, Nexa-team compite por especialización, claridad
operativa y trazabilidad antes que por amplitud funcional. Su diferenciación
consiste en conectar las necesidades comerciales del comprador con las
decisiones y tareas de los equipos que preparan, despachan y entregan los
pedidos. La etapa actual prioriza validar este flujo crítico mediante
experiencias web y móviles coherentes, mientras que las integraciones logísticas
de mayor profundidad, la automatización IoT y otras capacidades avanzadas se
consideran líneas de evolución sujetas a investigación, validación y
priorización posterior.

Esta sección presenta la identidad de Nexa-team, el contexto que motiva la
creación de Nexa, su modelo de negocio, su propuesta de valor, su misión, visión
y valores, así como los perfiles de los integrantes que participan en la
construcción de la solución.

### 1.1.1 Startup Description

**Nexa-team** es una startup de base tecnológica que desarrolla Nexa, una
solución digital para importadores, distribuidores y mayoristas B2B. Su
propósito es coordinar el ciclo comercial y operativo que conecta al comprador
con la disponibilidad, la preparación, el despacho y la entrega de sus
pedidos. La cadena de frío constituye una especialización relevante del
dominio, pero el producto no se limita exclusivamente a empresas que trabajan
con productos refrigerados o congelados.

El problema que orienta a la startup es la fragmentación de la información
entre compradores, coordinación comercial, almacén, despacho y entrega. En
este contexto, los pedidos pueden iniciar en conversaciones, llamadas, audios
u hojas de cálculo y ser reinterpretados varias veces antes de llegar a la
operación. Esta situación genera doble digitación, validaciones manuales,
incertidumbre sobre la disponibilidad y dificultades para mantener la
trazabilidad de las decisiones y evidencias.

Nexa propone reducir esa pérdida de continuidad mediante experiencias B2B
centradas en roles y respaldadas por un dominio compartido. La solución busca
ordenar la relación entre la intención comercial, el compromiso de compra, la
disponibilidad real de inventario y la ejecución física del pedido, sin
presentarse como un ERP completo ni reemplazar de inmediato todos los sistemas
administrativos, contables o logísticos de una empresa.

#### Modelo y propuesta de valor

Nexa-team plantea Nexa como una plataforma B2B, SaaS y multi-tenant. Cada
empresa contratante opera dentro de un Tenant, mientras que el Workspace
representa el entorno operativo asociado y mantiene una proyección uno-a-uno en
V1. Workspace y Tenant no son sinónimos ni deben interpretarse como un
contenedor C4, un bounded context o una regla de identidad y seguridad.

Dentro de cada tenant se mantienen aislados los usuarios, las relaciones
comerciales, los productos, las solicitudes, los compromisos, el inventario,
los documentos, las notificaciones y las reglas de acceso. La propuesta de
valor consiste en ofrecer una coordinación confiable y trazable entre la
demanda comercial y la operación de entrega, reduciendo la reconstrucción
manual de solicitudes, mejorando la visibilidad de la disponibilidad y
conservando evidencias importantes del proceso.

La solución se proyecta sobre superficies consistentes:

- Landing Page para comunicar el modelo de negocio e iniciar el registro.
- Internal Web Platform para la administración y las operaciones internas.
- Buyer Portal Web para la relación de compra autorizada.
- Nexa Operations Mobile para tareas operativas como recepción, preparación,
  traspaso al despacho y ejecución o prueba de entrega.
- Nexa Buyer Mobile para las acciones autorizadas y frecuentes del comprador
  B2B.

Las experiencias web y móviles proyectan el mismo dominio compartido y no
crean bounded contexts independientes. El producto se guía por los once
bounded contexts aceptados para Nexa, mantiene la API como autoridad y separa
las responsabilidades del dominio, las aplicaciones, los servicios y las
integraciones.

Nexa-team plantea una evolución progresiva del producto. La etapa actual
prioriza validar la coordinación de las tareas críticas del pedido B2B y de la
entrega mediante experiencias claras, trazables y consistentes. Las
integraciones logísticas de mayor profundidad, la automatización IoT y otras
capacidades avanzadas quedan como posibilidades futuras sujetas a
investigación, validación y priorización; no se presentan como funcionalidades
ya implementadas.
