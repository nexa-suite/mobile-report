# 1.2.2 Lean UX Process

Esta carpeta contiene los cuatro artefactos Lean UX indicados en el enunciado.
Se utiliza el Canvas de ocho boxes como estructura de razonamiento: Business
Problem, Business Outcomes, Users, User Outcomes and Benefits, Solutions,
Hypotheses, Learning y MVPs/Experiments. Todo el contenido de esta sección es
una declaración de supuestos iniciales; la segmentación móvil se consolida en
1.3 y la investigación posterior podrá modificar estas hipótesis.
