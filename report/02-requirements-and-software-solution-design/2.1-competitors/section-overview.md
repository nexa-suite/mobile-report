# 2.1 Competitors

Esta sección ubica a Nexa frente a productos digitales que cubren partes del trabajo comercial, administrativo, logístico o de seguimiento de una distribuidora B2B. El análisis se toma como referencia para la propuesta, pero no reemplaza la validación de mercado.

Se revisan competidores directos e indirectos, se organiza un landscape competitivo y se plantean estrategias y tácticas preliminares para las superficies actuales y móviles propuestas de Nexa.
