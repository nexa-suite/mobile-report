# 2.2.1 Interview Design

## Propósito de la entrevista

El diseño define las preguntas de la segmentación móvil vigente. Se cubren el
trabajo real, los canales, la tecnología, las frustraciones y las condiciones de
adopción; también se incluyen tareas físicas, conectividad, evidencia y handoff
cuando el alcance móvil actual lo exige.

El registro contiene ocho entrevistas. Sus respuestas orientan el informe y
alimentan hipótesis; cada ficha conserva el segmento, el rol y la evidencia
correspondiente.

## Segmentos y alcance

| Segmento | Registros disponibles | Alcance investigado | Límite de uso |
| :--- | :---: | :--- | :--- |
| `S1 — Commercial Coordination` | 3 | Captura comercial, validación de stock/crédito y trabajo en campo, dentro del alcance comercial diferido de `MOB-SEG-01`. | No demuestra tareas V1 de `Warehouse Operator` o `Dispatch Coordinator`. |
| `S2 — Operations / Account Owner` | 3 | Operación de `MOB-SEG-01`: trazabilidad documental, cadena de frío, inventario, vencimientos, FEFO y coordinación con almacén. | No representa evidencia directa de `MOB-SEG-02 — Delivery Workforce`. |

## Apertura y protocolo

La apertura de la entrevista es:

> Hola, gracias por darte este tiempo. Somos estudiantes de Ingeniería de
> Software y estamos investigando cómo se gestionan actualmente los pedidos y la
> coordinación operativa en la distribución de productos refrigerados. La idea
> no es evaluarte a ti ni a tu empresa, sino entender cómo trabajan hoy, qué
> dificultades aparecen y qué cosas les generan más carga o incertidumbre. La
> conversación durará aproximadamente entre 15 y 25 minutos; en algunos casos
> podría extenderse un poco más si aparece información valiosa. ¿Te parece bien
> si la grabamos sólo para revisar luego la información y no perder detalles?

Antes de registrar una nueva sesión se debe confirmar el propósito académico, el
uso de la grabación, el permiso para capturas, los límites de privacidad y el
derecho a no mostrar información confidencial. El moderador debe pedir un caso
real reciente, una excepción y el artefacto utilizado, separar lo que ocurre hoy
de lo que la persona desearía, y cerrar verificando el resumen.

## Guía para `MOB-SEG-01 — Field & Warehouse Operations`

Estas preguntas cubren el bloque operativo de `Operations / Account Owner` y lo
aterrizan a las tareas V1 de almacén y despacho.

| Tema | Preguntas abiertas |
| :--- | :--- |
| Rol y contexto | ¿Qué responsabilidad cumples en recepción, almacén, preparación o despacho y qué ocurre antes y después de tu tarea? |
| Flujo real | Cuéntame el último pedido completo desde que llegó la mercadería o la orden hasta que quedó preparado para despacho. |
| Recepción e identificación | ¿Cómo identificas el producto, lote, vencimiento y cantidad reales? ¿Qué haces si el código o la etiqueta no coincide? |
| Stock y condición | ¿Cómo compruebas que el stock visible coincide con lo que existe físicamente? ¿Qué información falta o llega tarde? |
| Frío y vencimiento | ¿Qué condiciones de temperatura, conservación o FEFO no se pueden perder de vista? ¿Cómo se registran hoy? |
| Picking y preparación | ¿Cómo eliges el lote y la cantidad correctos? ¿Qué errores o retrabajos aparecen al preparar un pedido? |
| Despacho y handoff interno | ¿Cómo sabes que el pedido está listo, quién lo recibe y qué evidencia queda de esa transferencia? |
| Excepciones | ¿Qué ocurre cuando falta stock, el lote no coincide, hay merma, un documento está incompleto o el pedido cambia? |
| Herramientas y acceso | ¿Qué usas hoy: ERP, Excel, teléfono, WhatsApp, documentos o etiquetas? ¿Quién puede consultar o corregir la información? |
| Adopción | Si pudieras mejorar una sola parte del trabajo móvil u operativo, ¿cuál sería? ¿Qué haría que una herramienta se use todos los días? |

### Alcance comercial diferido

Para los perfiles que antes se entrevistaron como `Commercial Coordination` se
conserva este bloque, pero sus respuestas se clasifican como contexto de
`Sales Representative` diferido: no se usan para afirmar que el almacén o el
despacho V1 ya fueron investigados.

- ¿Cómo comienza un pedido cuando llega por WhatsApp, llamada, audio, foto o
  lista?
- ¿En qué momento validas stock, precios, crédito o condiciones y con quién?
- ¿Cuántas veces debes volver a escribir, confirmar o corregir la información?
- ¿Cómo sabes si el pedido salió, se retrasó o tuvo una incidencia?
- ¿Qué debería resolver una herramienta móvil para acercarse a la rapidez de
  WhatsApp sin perder consistencia?

## Guía para `MOB-SEG-02 — Delivery Workforce`

No existe una entrevista directa de `Driver / Delivery Operator`. Este
guion define la campaña que todavía debe realizarse y evita inferir respuestas
desde los perfiles de almacén o compradores.

| Tema | Preguntas abiertas |
| :--- | :--- |
| Inicio de ruta | ¿Cómo recibes una entrega asignada y qué revisas antes de salir? |
| Contexto físico | ¿En qué momentos usas el teléfono, con qué mano o postura y qué limita tu atención durante la ruta? |
| Conectividad | ¿Dónde se pierde la conexión y qué haces si no puedes consultar o registrar el siguiente paso? |
| Intento de entrega | Cuéntame el último intento completo: llegada, contacto, entrega, rechazo o reprogramación. |
| Incidencias | ¿Cómo registras una dirección incorrecta, ausencia del comprador, faltante, daño o rechazo? |
| Evidencia | ¿Qué foto, código, firma, lectura o nota necesitas conservar para demostrar lo ocurrido? |
| Handoff | ¿Cómo se entrega el pedido y cómo sabes que la persona correcta lo recibió? |
| Seguridad y privacidad | ¿Qué datos del comprador, ruta o entrega no debería ver otro rol? |
| Recuperación | ¿Qué haces si la cámara, el scanner, la batería o la aplicación falla? |
| Adopción | ¿Qué tendría que hacer una herramienta para reducir llamadas sin volverse una carga durante la ruta? |

## Guía para `MOB-SEG-03 — B2B Buyers`

Estas preguntas retoman el guion de `B2B Buyer Portal`, pero priorizan
el alcance V1 actual de recepción, handoff y discrepancias.

| Tema | Preguntas abiertas |
| :--- | :--- |
| Negocio y rol | ¿Qué negocio atiendes y qué responsabilidad tienes al recibir o coordinar compras? |
| Abastecimiento | ¿Con qué frecuencia repones y qué productos no pueden faltar? |
| Aviso de entrega | ¿Cómo te enteras de que un pedido está en camino o listo para recibirlo? |
| Handoff | ¿Cómo verificas que el pedido y la persona que lo entrega corresponden a lo esperado? |
| Cantidades | ¿Cómo compruebas lo recibido y qué haces si la cantidad o el producto no coincide? |
| Discrepancias | Cuéntame el último faltante, daño, rechazo o diferencia y cómo se resolvió. |
| Visibilidad | ¿Qué información te obliga actualmente a llamar o escribir al proveedor? |
| Canales y dispositivos | ¿Usas WhatsApp, teléfono, Excel, una aplicación u otro canal? ¿Desde qué dispositivo? |
| Confianza | ¿Qué tendría que mostrar una herramienta para que la uses sin perder el soporte humano? |
| Cierre | Si pudieras simplificar una sola parte de la recepción, ¿cuál cambiarías primero? |

## Registro mínimo y reglas de análisis

Cada ficha debe conservar, cuando exista autorización: nombre y apellido, edad,
distrito, rol, segmento original y vigente, dispositivos, conectividad,
herramientas, fecha, inicio, fin, duración, consentimiento, captura, enlace
individual, enlace consolidado, preguntas aplicadas y resumen descriptivo.
Cuando el dato no aparezca en el registro se marca como `no disponible`;
no se completa por inferencia.

El análisis debe separar:

1. `OBSERVED`: algo descrito o mostrado en la entrevista.
2. `INTERPRETED`: patrón construido dentro de la muestra.
3. `PROPOSED`: implicación para el modelo o la interfaz móvil actual.
4. `CURRENT VALIDATED`: sólo después de completar la nueva campaña y la revisión
   humana de los registros.

Las frecuencias se calculan sobre el denominador real de cada grupo y siempre se
etiquetan como muestra registrada. No se presentan como porcentajes del mercado,
ni se crean personas o requisitos actuales a partir de la guía de preguntas.
