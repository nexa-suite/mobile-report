### 2.2.3 Interview Analysis

Esta sección analiza por separado las tres entrevistas de cada segmento objetivo. El
análisis utiliza únicamente información registrada en 2.2.2 y busca identificar, con
sustento estadístico, las características objetivas y subjetivas más recurrentes que
servirán de base para los arquetipos de la sección 2.3.

Los porcentajes deben declarar su base de cálculo. Cuando una variable no haya sido
respondida por todas las personas, el valor `NO DECLARADO` se trata como dato
faltante y la tabla debe indicar una base de respuestas válidas menor a tres en lugar de asumir una
respuesta. No se trasladan patrones de un segmento hacia otro.

#### Método de análisis

Para cada segmento se seguirá el mismo procedimiento:

1. Revisar las tres fichas y sus resúmenes descriptivos.
2. Codificar características objetivas y subjetivas con categorías consistentes.
3. Mantener una referencia a las entrevistas que sustentan cada categoría.
4. Calcular frecuencia, base de respuestas válidas y porcentaje.
5. Interpretar únicamente los patrones sustentados por la muestra del segmento.
6. Identificar qué características pasarán a la construcción del User Persona y qué
   información debe conservarse como variación individual.

La fórmula utilizada será:

`Porcentaje = (frecuencia de la categoría / base de respuestas válidas de respuestas) × 100`

Con tres respuestas válidas, las recurrencias posibles corresponden a 33.3 %, 66.7 %
y 100 %. Si la base de respuestas válidas es menor, debe calcularse el porcentaje con el denominador
real y declararlo explícitamente.
