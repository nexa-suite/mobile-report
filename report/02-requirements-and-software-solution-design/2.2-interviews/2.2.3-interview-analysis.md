## Traducción a la investigación móvil

| Evidencia histórica | Traducción segura | No se puede concluir |

| S1 antiguo de coordinación | Investigar cómo se captura una solicitud y se verifica stock/crédito cuando la persona trabaja fuera del escritorio. | Que el antiguo rol sea Warehouse Operator, que la captura móvil esté validada o que el sistema actual tenga una regla concreta. |

| S3 antiguo de comprador | Explorar atención de entrega, handoff, cantidades, discrepancias, recibo, evidencia y soporte. | Que catálogo, solicitudes, pagos, documentos o tracking completo sean necesidades actuales de Mobile V1. |
| S2 antiguo de operaciones | Usar preguntas sobre preparación, documentos, vencimiento y FEFO como contexto. | Que esos tres registros representen a conductores o satisfagan la muestra S2 nueva. |

La cadena de evidencia para una futura afirmación es: registro individual,
video/captura y consentimiento revisados; codificación con fuente; síntesis
por segmento; y revisión humana. Una historia sólo cambia de estado después de
esa cadena.

## Método de codificación

1. Revisar cada ficha contra video, captura, intervalo y consentimiento.
2. Separar observación, cita autorizada, interpretación, hipótesis y decisión
   del equipo.
3. Codificar cada registro con los mismos campos: tarea, frecuencia, costo del
   error, excepción, handoff, evidencia, conectividad, privacidad, ergonomía,
   seguridad y adopción.
4. Conservar casos negativos y desacuerdos; no borrar evidencia que contradiga
   una historia.
5. Calcular frecuencias por segmento usando el denominador real de registros
   válidos. El denominador histórico no se mezcla con el actual.
6. Derivar personas, journeys, empathy maps y cambios de historias sólo cuando
   exista una cadena de evidencia identificable.
7. Elevar contradicciones del backlog a revisión del equipo antes de cambiar
   alcance, estado o criterio de aceptación.

## Estados de evidencia

| Estado | Significado |
| :--- | :--- |
| `OBSERVED` | Acción o dato visto/escuchado en evidencia revisada |
| `INTERPRETED` | Lectura analítica separada de la observación |
| `PROPOSED` | Pregunta, hipótesis o diseño pendiente de contraste |
| `VALIDATED` | Evidencia revisada y aceptada con alcance explícito |
| `HISTORICAL_REUSE_PENDING` | Fuente antigua localizada, pero con gates de identidad, contenido, consentimiento o permiso pendientes |
| `RESEARCH_PENDING` | Investigación primaria aún no realizada o cerrada |

No se publican porcentajes, conclusiones, personas ni requisitos derivados de
entrevistas actuales hasta completar la muestra, la codificación y la revisión
humana.
