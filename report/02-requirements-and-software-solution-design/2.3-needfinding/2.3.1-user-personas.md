# 2.3.1 User Personas

Las personas de esta sección son instrumentos de Needfinding, no perfiles de
autorización, entidades de dominio ni prueba de adopción. La sección 1.3 define
los tres segmentos de investigación; la sección 2.2 delimita qué evidencia
directa existe para cada uno. No se infieren datos personales, métricas,
declaraciones textuales ni resultados de entrevistas que no estén registrados.

| Etiqueta de evidencia | Uso en estas fichas |
| --- | --- |
| `OBSERVED` | Hecho documentado en una ficha de entrevista del segmento. |
| `WORKING HYPOTHESIS` | Supuesto útil para preparar investigación, diseño o priorización; requiere contraste. |
| `RESEARCH PENDING` | Dato, comportamiento o condición sin evidencia directa suficiente. |
