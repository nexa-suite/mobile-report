# 2.3.1 User Personas

Todavía no se presentan User Personas validados para las aplicaciones móviles. `blueprint` define tres segmentos propuestos que servirán como punto de partida para la investigación:

1. Field & Warehouse Operations: Sales Representative, Warehouse Operator y Dispatch Coordinator.
2. Delivery Workforce: Driver / Delivery Operator.
3. B2B Buyers: Customer Buyer.

El Business Operations Manager participa como actor transversal para la supervisión y la toma de decisiones, pero no se agrega como un cuarto segmento móvil.

Las fichas definitivas deberán construirse después de las entrevistas. No se trasladan automáticamente las personas del proyecto Web, porque sus necesidades fueron recogidas para otra superficie y otro alcance.
