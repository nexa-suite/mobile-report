## 2.3. Needfinding

### 2.3.1. User Personas

Las personas constituyen los arquetipos de trabajo utilizados por el equipo
para organizar el diseño. Las entrevistas posteriores permiten contrastar y
enriquecer sus características.

Los nombres organizan los recorridos del informe; no identifican participantes
ni constituyen perfiles de autorización o entidades de dominio.

#### Mariela Torres — Warehouse & Dispatch Operations

| Aspecto | Arquetipo de trabajo |
| --- | --- |
| Rol | Explora tareas distintas de Warehouse Operator y Dispatch Coordinator sin fusionar sus responsabilidades. |
| Contexto | Recepción, identificación, preparación, readiness y Dispatch Handoff cerca de la mercadería. |
| Objetivo | Reconocer tarea, condición y responsable siguiente con contexto suficiente para continuar. |
| Información de trabajo | Producto, SKU, lote, cantidad, condición, prioridad, estado de preparación y evidencia de handoff. |
| Herramientas y canales a contrastar | Etiquetas, documentos, sistemas operativos, dispositivo, llamadas y mensajería usados en la operación. |
| Fricciones a explorar | Diferencias entre registro y físico, fuentes dispersas, cambios tardíos y traspasos ambiguos. |
| Perfil a caracterizar con consentimiento | Género, edad, distrito, estado civil, composición familiar, ocupación, habilidades, personalidad, influencias, dispositivo y canales preferidos. |

#### Diego Ramírez — Driver Delivery Execution

| Aspecto | Arquetipo de trabajo |
| --- | --- |
| Rol | Explora el trabajo de Driver o Delivery Operator durante una entrega asignada. |
| Contexto | Vehículo, ruta y punto de entrega, con cambios entre asignación, intento, incidencia y comunicación posterior. |
| Objetivo | Ejecutar el Delivery Attempt correcto y comunicar un resultado o una incidencia comprensibles. |
| Información de trabajo | Entrega, destino, contacto autorizado, instrucciones, evidencia permitida y estado de cada acción. |
| Herramientas y canales a contrastar | Teléfono, cámara, navegación, llamadas, mensajería, documentos y plataforma de trabajo. |
| Fricciones a explorar | Asignación incompleta, contacto insuficiente, interrupciones, conectividad limitada y evidencia asociada al intento equivocado. |
| Perfil a caracterizar con consentimiento | Género, edad, distrito, estado civil, composición familiar, ocupación, habilidades, personalidad, influencias, dispositivo y canales preferidos. |

#### Carlos Mendoza — B2B Buyers

| Aspecto | Arquetipo de trabajo |
| --- | --- |
| Rol | Explora el trabajo del Customer Buyer que participa en abastecimiento, seguimiento y recepción. |
| Contexto | Empresa compradora y punto de recepción, en coordinación con proveedor, personal interno y clientes propios. |
| Objetivo | Anticipar llegada, reconocer lo esperado y comunicar una diferencia con suficiente contexto. |
| Información de trabajo | Estado de entrega, productos y cantidades esperados, recepción, discrepancia, evidencia pertinente y canal de soporte. |
| Herramientas y canales a contrastar | Llamadas, mensajería, correo, hojas de cálculo, navegador y aplicaciones usadas para abastecimiento. |
| Fricciones a explorar | Incertidumbre de llegada, dependencia de coordinación manual y dificultad de explicar un cambio o diferencia. |
| Perfil a caracterizar con consentimiento | Género, edad, distrito, estado civil, composición familiar, ocupación, habilidades, personalidad, influencias, dispositivo y canales preferidos. |

#### Uso de las personas

Las personas organizan la User Task Matrix, los User Journey Maps, los Empathy
Maps, el Impact Mapping y las User Stories. Los hallazgos posteriores deben
conservar su fuente, contexto y alcance de interpretación.
