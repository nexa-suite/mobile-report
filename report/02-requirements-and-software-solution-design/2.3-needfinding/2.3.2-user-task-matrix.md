## Análisis de tareas identificadas

Las tareas identificadas muestran que Carlos Mendoza (MOB-SEG-03 B2B Buyers) participa en un proceso continuo de abastecimiento donde la disponibilidad de productos, la coordinación con proveedores y la previsibilidad de la llegada tienen impacto directo en la continuidad de su operación.

Las tareas con mayor frecuencia e importancia están relacionadas con conocer el estado del pedido y mantener comunicación con el proveedor. Esto evidencia que el comprador necesita reducir la incertidumbre durante el proceso de abastecimiento y contar con información suficiente para organizar la recepción de productos.

Asimismo, la resolución de excepciones mantiene una importancia relevante debido a que la relación comercial requiere soporte cuando aparecen diferencias, faltantes o situaciones que no pueden resolverse únicamente mediante un proceso estándar.

## Conclusión

La User Task Matrix evidencia que Carlos Mendoza (MOB-SEG-03 B2B Buyers) requiere principalmente visibilidad y control durante el proceso de abastecimiento. Las tareas identificadas se relacionan con mantener disponibilidad, coordinar compras, conocer el estado de llegada y resolver excepciones con el proveedor.
