# 2.3.2 User Task Matrix

La matriz de tareas se elaborará después de la investigación. Debe registrar actividades que los usuarios realizan independientemente de Nexa, no opciones de una aplicación.

Como guía inicial, se investigarán las siguientes tareas:

| Segmento propuesto | Tareas por validar |
| --- | --- |
| Field & Warehouse Operations | Consultar clientes y productos, verificar disponibilidad, registrar o preparar solicitudes, recibir y ubicar mercadería, revisar lotes y vencimientos, preparar pedidos y coordinar el despacho. |
| Delivery Workforce | Revisar entregas asignadas, preparar la ruta, confirmar un intento de entrega, registrar incidencias, obtener evidencia y cerrar la entrega. |
| B2B Buyers | Consultar la oferta, preparar una compra, enviar una solicitud o pedido, revisar cambios, seguir la entrega, reportar una discrepancia y consultar pagos o documentos. |

La frecuencia e importancia no se completan todavía. Asignarlas sin entrevistas produciría datos no sustentados.
