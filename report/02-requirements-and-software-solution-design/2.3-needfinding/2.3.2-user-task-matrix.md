### 2.3.2 User Task Matrix

La matriz ordena tareas del mundo real antes de proponer una interfaz. La
frecuencia y la importancia son referencias iniciales para preparar entrevistas
y pruebas; no son porcentajes ni resultados medidos. Cuando no existe
investigación directa, la valoración se mantiene como una hipótesis de trabajo.

| Valor | Frecuencia | Importancia |
| --- | --- | --- |
| Alta | Puede aparecer en la mayoría de casos o en cada ciclo de la tarea. | Si falla, puede detener o comprometer materialmente la continuidad del trabajo. |
| Media | Puede aparecer en una parte relevante de los casos o bajo condiciones específicas. | Afecta calidad, tiempo o coordinación, aunque existe una alternativa temporal. |
| Baja | Puede aparecer de forma excepcional o ante una excepción. | Es útil resolverla, pero no define por sí sola el flujo principal. |
| Por contrastar | Aún no hay evidencia suficiente para una valoración responsable. | Aún no hay evidencia suficiente para una valoración responsable. |

| Tarea del mundo real | Warehouse & Dispatch | Driver Delivery Execution | B2B Buyers | Fundamento para investigar |
| --- | --- | --- | --- | --- |
| Reconocer qué pedido, entrega o mercadería atender | Alta / Alta | Alta / Alta | Media / Alta | Contrastar la información mínima que permite identificar el trabajo correcto. |
| Consultar disponibilidad, preparación o estado relevante | Alta / Alta | Media / Media | Alta / Alta | Las entrevistas Buyer muestran interés por visibilidad de llegada; los demás contextos requieren observación directa. |
| Identificar producto, lote, cantidad o condición | Alta / Alta | Media / Media | Por contrastar / Alta | Observar qué datos se revisan realmente durante operación y recepción. |
| Preparar una salida o reconocer que está lista para handoff | Alta / Alta | Media / Media | Baja / Baja | Explorar la transición entre preparación, readiness y responsabilidad siguiente. |
| Ejecutar un Delivery Attempt y registrar su resultado | Baja / Media | Alta / Alta | Baja / Media | Verificar el trabajo de campo sin convertir el resultado local en verdad autoritativa. |
| Asociar evidencia al hecho correcto | Media / Alta | Alta / Alta | Media / Alta | Distinguir evidencia, resultado e incidencia en cada segmento. |
| Consultar el estado de llegada de una entrega | Baja / Media | Media / Media | Alta / Alta | Las entrevistas Buyer orientan esta tarea; se debe conocer intensidad y contexto. |
| Coordinar una recepción, llegada o excepción | Media / Alta | Alta / Alta | Alta / Alta | Observar canales, responsables y momento de escalamiento. |
| Comparar esperado con recibido y comunicar una discrepancia | Por contrastar / Media | Baja / Media | Por contrastar / Alta | Levantar un caso completo de recepción y discrepancia antes de fijar el flujo. |
| Retomar una tarea tras una interrupción | Media / Alta | Alta / Alta | Media / Media | Contrastar la necesidad de recuperación sin asumir sincronización offline. |

La priorización resultante concentra el aprendizaje inicial en tres recorridos:
continuidad de preparación y handoff, ejecución atribuible de Delivery Attempt y
recepción Buyer con contexto. La matriz no sustituye la investigación de campo ni
prueba que una capacidad esté implementada.
