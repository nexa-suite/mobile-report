# 2.3.3 User Journey Mapping

Los User Journey Maps deberán representar el recorrido As-Is de cada segmento móvil, antes de atribuirle una solución de Nexa.

El alcance de investigación comprende tres recorridos: la coordinación de una tarea comercial u operativa, la ejecución de una entrega y la compra B2B con posterior seguimiento. Se deberán identificar acciones, canales, momentos de espera, problemas, emociones y oportunidades de mejora.

No se reutilizan como journeys móviles los diagramas del proyecto Web. Pueden servir como antecedente del flujo comercial compartido, pero no describen necesariamente el trabajo en campo, la conectividad o la entrega física.

## Información pendiente

Faltan los recorridos observados, sus etapas, puntos de contacto, pain points, gains y capturas de los diagramas elaborados en la herramienta indicada.
