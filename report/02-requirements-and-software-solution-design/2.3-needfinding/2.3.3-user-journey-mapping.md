# 2.3.3 User Journey Mapping

Los tres recorridos son **As-Is candidate maps**: organizan lo que se debe
levantar en casos recientes, no describen una experiencia terminada de Nexa.
Los pensamientos, estados emocionales, pains y oportunidades se marcan como
hipótesis cuando no existe evidencia directa. Ningún recorrido Web se reutiliza
como prueba del contexto físico móvil.

Los mapas deben actualizarse únicamente con fuente, denominador y evidencia de
caso reciente. Hasta entonces sirven para ordenar la observación, no para
atribuir emociones, decisiones o métricas a una población.
