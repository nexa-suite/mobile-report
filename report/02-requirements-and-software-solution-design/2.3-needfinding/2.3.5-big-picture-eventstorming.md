# 2.3.5 Big Picture EventStorming

El Big Picture EventStorming se utilizará para observar el dominio de Nexa de extremo a extremo, sin dividirlo primero por aplicaciones. El flujo compartido parte de la habilitación del tenant y la relación con compradores, continúa con el catálogo y el compromiso comercial, y llega a la disponibilidad, el fulfillment, la entrega, los documentos, los pagos y la trazabilidad.

En esta vista Mobile representa diferentes puntos de interacción con el mismo dominio. No se crearán eventos de dominio para cámara, mapas, notificaciones push, almacenamiento local o sincronización; esos elementos pertenecen a la aplicación o a la integración, salvo que una sesión de dominio posterior demuestre una regla de negocio distinta.

El EventStorming anterior se conservará solo como referencia de trabajo. La versión actual debe alinearse con los 11 Bounded Contexts aceptados en `blueprint` y mantenerse separada de los diagramas estratégicos que se documentarán en la sección 2.5.
