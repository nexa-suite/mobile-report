# 2.4.1 User Stories

Las historias móviles se tomarán del catálogo propuesto en `blueprint/03-mobile/requirements`. Actualmente existen siete Epics y 49 historias con identificadores `MOB-US-001` a `MOB-US-049`. Su estado es propuesto y la validación de investigación y los criterios de aceptación todavía están pendientes.

## Epics móviles

| Epic | Nombre | Aplicación principal |
|---|---|---|
| MOBILE-EPIC-01 | Access & Context | Operations Mobile y Buyer Mobile |
| MOBILE-EPIC-02 | BOM & Sales | Operations Mobile |
| MOBILE-EPIC-03 | Warehouse Mobile Operations | Operations Mobile |
| MOBILE-EPIC-04 | Dispatch Mobile | Operations Mobile |
| MOBILE-EPIC-05 | Driver / Delivery Execution | Operations Mobile |
| MOBILE-EPIC-06 | Buyer Mobile Commerce | Buyer Mobile |
| MOBILE-EPIC-07 | Buyer Delivery Experience | Buyer Mobile |

Las historias se relacionan con los Bounded Contexts compartidos. No se agrega un Bounded Context Mobile ni se inventan criterios Gherkin para historias que todavía no han sido refinadas con usuarios y equipo técnico.
