# 2.4.3 Product Backlog

El Product Backlog deberá organizar las historias móviles por valor para el negocio y no únicamente por orden técnico. El catálogo de referencia está compuesto por las siete Epics y 49 historias `US` incluidas en la versión actualizada de User Stories recibida para este reporte.

En esta etapa no se asignan story points, sprints ni un orden definitivo porque esos datos todavía no están definidos para el producto móvil. Las historias del antiguo backlog Web no se trasladan automáticamente; solo podrán conservarse como dependencias compartidas si el equipo confirma que siguen dentro del alcance.
