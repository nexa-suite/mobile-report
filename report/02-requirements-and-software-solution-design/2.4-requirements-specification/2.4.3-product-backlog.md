# Product Backlog

El orden académico separa claramente la adquisición pública, las historias funcionales Mobile, la habilitación técnica y la investigación. Todas las filas tienen una planificación S1–S4; V4/Future identifica únicamente una proyección de release y no crea un Sprint adicional.

## Orden por tipo

1. Landing User Stories (LAND-US).
2. Mobile Functional User Stories (MOB-US), agrupadas por release.
3. Technical Stories (TS-MOB).
4. Spike Stories (SPIKE).
