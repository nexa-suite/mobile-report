# 2.5.1.0 DDD Process Evidence and Visual Mapping

## Reading rule

The following visuals are the complete `nexa-ddd` set found in the external
source directory at the 2026-09-06 inspection: steps 1–7, 9 and 10. They are
useful process evidence and design input, but they are not a signed workshop
record. The source directory has no Git metadata or embedded date/author
provenance. Each source SVG is hashed in the
[Chapter 2 provenance register](../../../assets/chapter-2/provenance.md).

Every caption separates observed content from interpretation. `TARGET` means
the accepted design direction; `AS-IS` means verified implementation evidence.
No visual creates a new Bounded Context or transfers authority to Mobile.
