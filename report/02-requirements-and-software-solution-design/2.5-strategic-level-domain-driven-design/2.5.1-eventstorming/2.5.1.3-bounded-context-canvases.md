# 2.5.1.3 Bounded Context Canvases

Los Bounded Context Canvases deberán seguir el límite y la autoridad de los 11 contextos aceptados por Nexa. Para cada canvas se deberá documentar el propósito, el lenguaje del contexto, sus reglas, capacidades, dependencias y decisiones de diseño.

| Código | Bounded Context |
|---|---|
| BC-01 | Tenant & Access Governance |
| BC-02 | Customer & Buyer Relationships |
| BC-03 | Catalog & Commercial Policy |
| BC-04 | Sales Commitment |
| BC-05 | Inventory Availability |
| BC-06 | Fulfillment & Delivery |
| BC-07 | Credit & Receivables |
| BC-08 | Payments |
| BC-09 | Business Documents |
| BC-10 | Notifications |
| BC-11 | Business Traceability |

No se elaborará un canvas independiente para Operations Mobile o Buyer Mobile porque son proyecciones de producto.

## Información pendiente

Faltan los canvases elaborados durante el taller y la crítica de diseño del equipo. Esta lista funciona como índice alineado con `blueprint`, no como evidencia de que todos los canvases ya hayan sido discutidos.
