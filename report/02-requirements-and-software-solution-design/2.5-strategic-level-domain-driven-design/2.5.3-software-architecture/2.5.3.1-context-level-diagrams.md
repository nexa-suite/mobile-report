# 2.5.3.1 Software Architecture Context-Level Diagrams

El Context Diagram deberá mostrar a Nexa como una plataforma B2B SaaS
multi-tenant rodeada por sus actores y sistemas externos. Los actores legibles
son Prospective Customer Representative, Internal Tenant Workforce y B2B
Buyer. La proyección móvil no reemplaza estas categorías: Warehouse Operator,
Dispatch Coordinator y Driver or Delivery Operator pertenecen al workforce
interno; Customer Buyer pertenece al comprador B2B.

Las dependencias externas se representan de manera abstracta: Payment
Provider, Email Delivery Service y Maps & Geolocation Provider. No se agregan
proveedores concretos ni integraciones futuras como si formaran parte de V1.

El corte de diseño incluye vistas AS-IS, V1 TARGET y Future Runway. Operations
Mobile y Buyer Mobile pertenecen a la vista V1 TARGET con la etiqueta TARGET V1
/ PLANNED / PROPOSED: son proyecciones de producto y arquitectura aceptadas para
V1, no capacidades implementadas. Su presencia no demuestra cliente nativo o
multiplataforma, runtime, aceptación de producto ni preparación para
producción. Los elementos que no forman parte de V1 permanecen en Future
Runway.

## Mapeo de actores para la proyección objetivo

| Actor de contexto | Rol Mobile | Superficie | Historias V1 relacionadas |
| :--- | :--- | :--- | :--- |
| Internal Tenant Workforce | Warehouse Operator | Operations Mobile | MOB-US-011..019 |
| Internal Tenant Workforce | Dispatch Coordinator | Operations Mobile | MOB-US-020..025 |
| Internal Tenant Workforce | Driver or Delivery Operator | Operations Mobile | MOB-US-026..034 |
| B2B Buyer | Customer Buyer | Buyer Mobile | MOB-US-044, MOB-US-047..049 |
| Internal Tenant Workforce / authorized context | Mobile User | Ambas superficies | MOB-US-001..003 |

Este mapeo ayuda a la trazabilidad del objetivo. No es una lista de
participantes y no demuestra que un actor haya aceptado el diseño.
