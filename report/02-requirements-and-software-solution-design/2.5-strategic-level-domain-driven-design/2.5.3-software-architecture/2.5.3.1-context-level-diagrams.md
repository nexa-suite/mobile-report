# 2.5.3.1 Software Architecture Context-Level Diagrams

El Context Diagram deberá mostrar a Nexa como una plataforma B2B SaaS multi-tenant rodeada por sus actores y sistemas externos. Los actores legibles son Prospective Customer Representative, Internal Tenant Workforce y B2B Buyer.

Las dependencias externas se representan de manera abstracta: Payment Provider, Email Delivery Service y Maps & Geolocation Provider. No se agregan proveedores concretos ni integraciones futuras como si formaran parte de V1.

La fuente para el diagrama es `blueprint/01-shared/architecture/c4`. La aplicación móvil se incorporará únicamente en la vista propuesta o de runway que corresponda, no como una capacidad implementada de V1.
