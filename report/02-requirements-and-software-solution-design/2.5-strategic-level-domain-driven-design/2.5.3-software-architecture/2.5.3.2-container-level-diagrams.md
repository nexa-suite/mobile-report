#### 2.5.3.2. Software Architecture Container Level Diagrams

El Container Diagram separa superficies, autoridad de API y almacenamiento. Un
container C4 es una unidad ejecutable o almacenable del sistema; no equivale a
un Bounded Context.

##### Containers de Nexa

| Container | Responsabilidad de diseño | Límite |
| --- | --- | --- |
| Nexa Website | Superficie pública para contenido comercial y CTA. | No autoriza decisiones de negocio. |
| Nexa Platform | Superficie operativa del workforce. | Consume contratos del API. |
| Nexa Buyer Portal | Superficie B2B de autoservicio. | Consume contratos del API. |
| Nexa API | Autoridad de dominio, seguridad, workflows, integraciones y persistencia. | Expone contratos REST/OpenAPI. |
| PostgreSQL | Persistencia transaccional compartida. | Ownership lógico y predicados por Tenant/Workspace y contexto. |
| Object Storage | Bytes de documentos y media. | Acceso mediante referencias autorizadas. |
| Operations Mobile | Cliente planificado para la operación. | Estado local no autoritativo. |
| Buyer Mobile | Cliente planificado para el comprador B2B. | Estado local no autoritativo. |

No se agrega un backend Mobile separado. La autoridad transaccional, la
autorización, la idempotencia y los hechos confirmados permanecen en Nexa API.

##### Tecnología y comunicación

| Elemento | Línea base | Contrato de frontera |
| --- | --- | --- |
| Nexa API | Java 25, Spring Boot 4.1.x y Spring Modulith. | REST/OpenAPI, autorización, transacciones e integraciones. |
| PostgreSQL | PostgreSQL compartido. | Predicados y ownership lógico por Tenant/Workspace y contexto. |
| Object Storage | S3-compatible. | Ports/adapters y referencias autorizadas; no URL pública implícita. |
| Website, Platform y Buyer Portal | Superficies de producto. | Consumen el API sin autoridad duplicada. |
| Operations Mobile y Buyer Mobile | Framework abierto bajo la decisión vigente. | Clientes planificados; estado local no autoritativo. |

Payment Provider, Email Delivery Service y Maps & Geolocation Provider
permanecen abstractos hasta que exista proveedor y prueba reproducible.
