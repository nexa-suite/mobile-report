# 2.5.3.3 Software Architecture Component-Level Diagrams

Esta sección se incorpora para cubrir el componente de arquitectura solicitado por el enunciado. Los diagramas deberán mostrar componentes dentro de los containers, sin confundirlos con Bounded Contexts.

La fuente de referencia será la cobertura de componentes de C4 en `blueprint/01-shared/architecture/c4`. Las vistas móviles se tratarán como propuestas y las vistas del API se presentarán según la evidencia de implementación o de diseño disponible.
