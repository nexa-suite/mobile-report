# 2.5.3.4 Software Architecture Deployment Diagrams

El diagrama de despliegue se presentará como una vista del runtime que esté respaldada por evidencia. El proyecto anterior contiene una propuesta de infraestructura que no debe confundirse con un deployment productivo aprobado.

La evidencia disponible en `blueprint` distingue el runtime local basado en Docker Compose de una arquitectura de despliegue cloud. Por ello, el documento podrá describir el entorno local AS-IS y señalar como pendiente cualquier decisión sobre nodos productivos, redes, escalamiento, secretos, disponibilidad y observabilidad.

No se afirmará que las aplicaciones móviles, proveedores externos o servicios cloud estén desplegados si no existe evidencia de ello.
