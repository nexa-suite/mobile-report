# 2.6.1 Bounded Context Tactical Coverage

## Propósito y estado

Esta vista da al informe un lugar para trazar las cuatro capas tácticas sin
presentar Mobile ni cada contexto objetivo como implementación terminada. Las
filas son objetivos de diseño alineados con el modelo estratégico adoptado.
Una implementación verificada sólo se agregará con archivo verificable,
commit, prueba u otra evidencia reproducible.

## Reglas tácticas

- Un Aggregate posee la consistencia local; un identificador entre contextos no es un grafo de objetos compartido.
- Un repository pertenece al contexto que posee la invariante o el modelo persistido. PostgreSQL compartido no implica ownership compartido.
- Los application handlers coordinan casos de uso y transacciones; no convierten al cliente Mobile en Domain Layer.
- Los contratos de interfaz deben identificar autorización, idempotencia, error y semántica de resultado desconocido antes de considerar completo un cliente.
- Los infrastructure adapters traducen proveedores externos y persistencia; no definen el vocabulario del producto.
