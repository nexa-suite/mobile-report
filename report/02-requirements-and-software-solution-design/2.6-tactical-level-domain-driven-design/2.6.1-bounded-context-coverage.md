## Tactical rules

- An Aggregate owns local consistency; a cross-context identifier is not a
  cross-context object graph.
- A repository belongs to the context that owns the invariant or persisted
  model. Shared PostgreSQL does not imply shared ownership.
- Application handlers coordinate use cases and transactions; they do not make
  the Mobile client a domain layer.
- Interface contracts must identify authorization, idempotency, error and
  unknown-result semantics before a client implementation is called complete.
- Infrastructure adapters translate external providers and persistence; they
  do not define product vocabulary.
