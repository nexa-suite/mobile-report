# 2.6.x.3 Application Layer

En esta capa se documentarán los flujos de negocio, Command Handlers y Event Handlers necesarios para ejecutar los procesos del Bounded Context. Se deberá relacionar cada flujo con las capabilities correspondientes y distinguir una decisión transaccional de una proyección o notificación.

## Uso de la plantilla

Los casos de uso objetivo y la evidencia AS-IS disponible están descritos en
los once paquetes de [bounded-contexts](../bounded-contexts/). La plantilla no
prueba manejadores implementados.
