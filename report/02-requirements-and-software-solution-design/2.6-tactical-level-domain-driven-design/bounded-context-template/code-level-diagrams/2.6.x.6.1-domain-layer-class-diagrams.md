## Diccionario de clases del candidato BC-06

La siguiente transcripción conserva los miembros, visibilidad y operaciones
de [`domain-model.puml`](../../../../../../blueprint/01-shared/domain/bounded-contexts/BC-06-fulfillment-delivery/diagrams/domain-model.puml).
Las dependencias `SalesOrder` y `PhysicalAllocation` son referencias estables
de otros contextos; no se convierten en objetos compartidos ni en agregados de
BC-06.

| Clase | Categoría | Atributos relevantes | Operaciones públicas / responsabilidad |
| :--- | :--- | :--- | :--- |
| `Fulfillment` | Aggregate Root | `-fulfillmentId: FulfillmentId`; `-salesOrderId: SalesOrderId`; `-status: FulfillmentStatus` | `+start()`; `+complete()`; `+cancel(reason)`; coordina el plan de fulfillment |
| `FulfillmentLine` | Entity | `-lineId: FulfillmentLineId`; `-fulfillmentId: FulfillmentId`; `-skuId: SkuId`; `-plannedQuantity: Quantity` | `+recordPicked(quantity)`; conserva la cantidad planificada y pickeada |
| `PickingResult` | Entity | `-pickingResultId: PickingResultId`; `-fulfillmentId: FulfillmentId`; `-status: PickingStatus`; `-completedAt: Instant` | `+confirm()`; `+flagDiscrepancy()`; registra el resultado del picking |
| `PickingDiscrepancy` | Entity | `-discrepancyId: PickingDiscrepancyId`; `-pickingResultId: PickingResultId`; `-kind: DiscrepancyKind`; `-quantity: Quantity` | `+resolve()`; conserva la excepción y su resolución |
| `Delivery` | Aggregate Root | `-deliveryId: DeliveryId`; `-fulfillmentId: FulfillmentId`; `-status: DeliveryStatus`; `-destinationSnapshot: DestinationSnapshot` | `+dispatch()`; `+attempt()`; `+complete()`; `+openContinuation()`; conserva obligación y destino congelado |
| `DeliveryAssignment` | Entity | `-assignmentId: DeliveryAssignmentId`; `-deliveryId: DeliveryId`; `-operatorId: OperatorId`; `-vehicleReference: String` | `+assign()`; `+unassign()`; mantiene asignaciones de la entrega |
| `DeliveryAttempt` | Entity | `-attemptId: DeliveryAttemptId`; `-deliveryId: DeliveryId`; `-attemptNumber: Integer`; `-outcome: AttemptOutcome` | `+recordOutcome(outcome)`; conserva cada intento bajo la misma entrega |
| `DeliveryAttemptLine` | Entity | `-lineId: DeliveryAttemptLineId`; `-attemptId: DeliveryAttemptId`; `-skuId: SkuId`; `-quantity: Quantity` | `+record()`; registra líneas observadas en el intento |
| `DeliveryQuantityOutcome` | Entity | `-outcomeId: DeliveryQuantityOutcomeId`; `-attemptId: DeliveryAttemptId`; `-fulfilledQuantity: Quantity`; `-shortQuantity: Quantity` | `+record()`; separa entregado y faltante |
| `ProofOfDelivery` | Aggregate Root | `-podId: ProofOfDeliveryId`; `-deliveryId: DeliveryId`; `-status: PodStatus`; `-capturedAt: Instant` | `+capture()`; `+seal()`; mantiene la evidencia POD inmutable |
| `ProofOfDeliveryAddendum` | Entity | `-addendumId: PodAddendumId`; `-podId: ProofOfDeliveryId`; `-reason: String` | `+append()`; corrige mediante anexo, sin sobrescribir el POD |
| `TemperatureEvidence` | Entity | `-evidenceId: TemperatureEvidenceId`; `-deliveryId: DeliveryId`; `-capturedAt: Instant`; `-temperatureCelsius: Decimal` | `+record()`; conserva evidencia manual de temperatura |
| `TemperatureExcursion` | Entity | `-excursionId: ExcursionId`; `-deliveryId: DeliveryId`; `-status: ExcursionStatus` | `+placeOnHold()`; `+disposition()`; mantiene el ciclo de la excepción |
| `ContinuationDelivery` | Entity | `-continuationId: ContinuationDeliveryId`; `-parentDeliveryId: DeliveryId`; `-status: ContinuationStatus` | `+open()`; `+close()`; representa la obligación restante, no un intento adicional |
| `DeliveryExecutionPolicy` | Domain Service | Sin estado propio | `+canComplete(delivery, pod)`; `+requiresContinuation(outcome)`; aplica reglas que cruzan entidades del agregado |
| `DestinationSnapshot` | Value Object | `-recipientName: String`; `-addressLine: String`; `-districtCode: String` | Valor inmutable que congela el destino de la entrega |
| `DeliveryRepository` | Repository interface | — | `+findById(id)`; `+save(delivery)`; puerto para el agregado `Delivery` |

Enumeraciones de la fuente: `FulfillmentStatus`, `DeliveryStatus`,
`AttemptOutcome`, `PodStatus`, `ExcursionStatus` y `ContinuationStatus`.
