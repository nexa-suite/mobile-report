# 2.6.x.6 Bounded Context Software Architecture Code-Level Diagrams

Esta sección reunirá el Class Diagram del Domain Layer y el Database Diagram del Bounded Context seleccionado. Los diagramas deberán reflejar únicamente clases, relaciones, tablas y constraints sustentados por código actual o por un diseño objetivo identificado como tal.

No se crearán diagramas de código para Mobile como si la aplicación fuese un Bounded Context.
