### 3.1.2 Arquitectura de información

#### 3.1.2.1 Sistemas de organización

##### Website público

El repositorio Website contiene 15 páginas HTML agrupadas en producto público,
solución, empresa, precios, FAQ, buyer portal, platform y áreas legales. Es una
jerarquía de descubrimiento público; no es la IA operativa autorizada.

##### Estructura propuesta para Mobile

| Surface | Primary hierarchy | Scope |
| :--- | :--- | :--- |
| Operations Mobile | Context → assigned work → task detail → command/evidence → result/history | Warehouse, dispatch and delivery V1 stories |
| Buyer Mobile | Context → delivery attention → handoff verification → receipt/discrepancy → history | Buyer handoff and receipt V1 stories |

La jerarquía es secuencial para un command, pero las vistas de lista/detalle
pueden ser matriciales cuando el rol tiene varios elementos asignados. La
persona puede volver al trabajo actual sin perder el estado visible, pero los
datos protegidos sólo se muestran después de confirmar la autorización.

El inventario de páginas Mobile, sus etiquetas y la agrupación de pantallas se
documentan como base para los wireframes. Esta entrega no incluye la revisión
UX ni los wireframes visuales resultantes.
