# 3.1.2.1 Organization Systems

## Web AS-IS

The Website repository contains 15 HTML pages grouped into public product,
solution, company, pricing, FAQ, buyer portal, platform and legal areas. This
is a public discovery hierarchy; it is not the authorized operational IA.

## Mobile TARGET

| Surface | Primary hierarchy | Scope |
| :--- | :--- | :--- |
| Operations Mobile | Context → assigned work → task detail → command/evidence → result/history | Warehouse, dispatch and delivery V1 stories |
| Buyer Mobile | Context → delivery attention → handoff verification → receipt/discrepancy → history | Buyer handoff and receipt V1 stories |

The hierarchy is sequential for a command, but list/detail views may be
matricial when the role has multiple assigned items. A user can return to the
current work without losing the visible state, but protected data is rendered
only after authorization is confirmed.

The current Mobile page inventory, labels and screen grouping require a human
UX review before being converted into a final wireframe.
