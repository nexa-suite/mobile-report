### 3.1.2 Information Architecture

#### 3.1.2.1 Organization Systems

La información se agrupa por audiencia, tarea y resultado. El sitio público organiza contenido para conocer el producto; las superficies Mobile presentan primero el trabajo permitido por su contexto y luego el detalle necesario para completarlo.

| Superficie | Organización | Secuencia de tarea | Resultado visible |
| --- | --- | --- | --- |
| Website | Producto, soluciones, equipo, soporte y contenido legal | Necesidad → alcance → información relacionada → siguiente destino | Qué ofrece el sitio y qué acción puede realizar la persona visitante. |
| Operations Mobile — almacén y despacho | Trabajo asignado, con listas y detalle | Contexto → tarea → producto → acción o evidencia → resultado | Ítem, cantidad, estado y confirmación vinculados a la tarea. |
| Operations Mobile — entrega | Entrega e intento actual | Asignación → intento → resultado → evidencia → consulta de estado | Entrega, intento y estado de evidencia. |
| Buyer Mobile | Entrega vinculada a una relación autorizada | Transferencia → cantidades → recepción o discrepancia → historial | Cantidades recibidas, diferencia y resultado. |

Las listas permiten comparar tareas del mismo contexto; el detalle prioriza identidad, estado, acción y recuperación. El historial permite revisar hechos anteriores sin sustituir el resultado vigente.
