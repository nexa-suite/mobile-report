# 3.1.2.3 SEO Tags and Meta Tags

## Web AS-IS

The Website pages include HTML language metadata, title/description and Open
Graph fields, with canonical URLs pointing to the historical academic site
address in the source. This is a static-site implementation fact, not proof of
deployment, indexing or conversion performance. A page-by-page metadata audit
and browser capture remain pending.

## Mobile TARGET and ASO

Operations Mobile and Buyer Mobile require an app name, short description,
long description, icon, screenshots, privacy/contact destination and release
notes only when a distributable client is actually selected. No store listing,
package, install or ASO result is asserted in this report. Mobile operational
labels must not be optimized at the expense of authorization, safety or
traceability.
