#### 3.1.2.4 Searching Systems

En Buyer, la búsqueda parte del catálogo. El comprador puede escribir el nombre del producto, una marca o un SKU. Puede acotar la consulta por categoría, familia, variante, marca, disponibilidad y condición de conservación. Los resultados muestran el nombre, la presentación, el precio y la disponibilidad que devuelve el catálogo. Desde un resultado se abre la ficha y se elige el producto para el borrador.

En Operations, el personal de almacén puede buscar por nombre, SKU o presentación y filtrar por marca o categoría. Los resultados muestran datos para distinguir variantes antes de abrir la ficha. El lector de códigos resuelve un identificador físico. Si el código es desconocido o ambiguo, o si la cámara no está disponible, la consulta manual permite continuar. El flujo comprueba el SKU antes de usarlo en la tarea de almacén.
