# 3.1.2.4 Searching Systems

## Current boundary

The 28 V1 stories do not authorize a generic global search capability. The
Website provides public navigation and page content; the current report does
not claim an authenticated operational search implementation.

## Mobile TARGET

| Search need | Surface | Result requirements | State |
| :--- | :--- | :--- | :--- |
| Identify Product/SKU or lot | Operations Mobile | Authorized scope, identifier, lot/expiry context and manual fallback | Target; SPIKE-003 pending |
| Find assigned dispatch/delivery work | Operations Mobile | Role-limited list, current status, stable Delivery/Attempt identity | Target; contract pending |
| Open a buyer delivery | Buyer Mobile | Authorized relationship, handoff code or permitted update | Target; MOB-US-044/047 |

Results must show the source context, status and last confirmed time. Empty,
ambiguous, unauthorized, expired and unavailable results are first-class
states. Local indexes may assist presentation but cannot grant access or
confirm a business fact.
