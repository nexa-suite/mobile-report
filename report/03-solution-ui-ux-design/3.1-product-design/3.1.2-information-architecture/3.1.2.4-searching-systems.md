# 3.1.2.4 Searching Systems

## Current boundary

Las 28 historias V1 no autorizan una capability de búsqueda global genérica.
Website proporciona navegación pública y contenido de páginas; el informe
actual no afirma una implementación de búsqueda operativa autenticada.

## Mobile TARGET

| Search need | Surface | Result requirements | State |
| :--- | :--- | :--- | :--- |
| Identify Product/SKU or lot | Operations Mobile | Authorized scope, identifier, lot/expiry context and manual fallback | Target; SPIKE-003 pending |
| Find assigned dispatch/delivery work | Operations Mobile | Role-limited list, current status, stable Delivery/Attempt identity | Target; contract pending |
| Open a buyer delivery | Buyer Mobile | Authorized relationship, handoff code or permitted update | Target; MOB-US-044/047 |

Los resultados deben mostrar el contexto de origen, el estado y la última hora
confirmada. Los resultados vacíos, ambiguos, no autorizados, expirados y no
disponibles son estados de primera clase. Los índices locales pueden ayudar a
la presentación, pero no pueden conceder acceso ni confirmar un hecho de
negocio.
