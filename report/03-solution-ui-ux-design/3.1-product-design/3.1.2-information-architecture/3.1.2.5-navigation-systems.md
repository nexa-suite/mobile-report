#### 3.1.2.5 Navigation Systems

La navegación mantiene visible el contexto de la persona, la tarea y el resultado que puede comprobar. Volver conserva un estado seguro y no repite por sí mismo una acción que pudiera duplicar un registro.

| Superficie y tarea | Actor de referencia | Recorrido principal | Regla de continuidad |
| --- | --- | --- | --- |
| Website público | Public Interested Company / Prospect | Inicio → producto o solución → detalle → FAQ, contenido legal o inicio de onboarding | Conservar el idioma y el acceso a los destinos públicos. |
| Operations Mobile — almacén y despacho | Warehouse Operator / Dispatch Coordinator | Sesión → contexto autorizado → trabajo asignado → Product/SKU → acción o evidencia → resultado | Volver al último estado seguro y comprobar el contexto antes de mostrar información de trabajo. |
| Operations Mobile — entrega | Driver / Delivery Operator | Sesión → entrega asignada → intento actual → resultado → evidencia → historial | Mantener juntos la entrega, el intento y su resultado. |
| Buyer Mobile | Customer Buyer | Relación autorizada → transferencia → cantidades → recepción o discrepancia → historial | Mantener separado el resultado del conductor y la recepción del comprador. |

Si vence la sesión o cambia la autorización del contexto, la interfaz retorna a una entrada segura antes de mostrar datos protegidos. Una interrupción de red conserva la última respuesta confirmada y presenta la acción como pendiente hasta consultar su estado; el control para volver a intentar se ofrece después de comprobar el resultado previo. Un código inválido o vencido detiene la recepción y explica el siguiente paso permitido. Volver o reintentar no crea otro comprobante, entrega, intento ni discrepancia de manera silenciosa.

La navegación mantiene el trabajo actual delante del historial, conserva los datos ya revisados y presenta los estados de recuperación junto al elemento afectado. Un cambio de contexto vuelve a comprobar las vistas visibles antes de continuar; una ruta compartida tampoco abre información protegida sin verificar el contexto vigente.
