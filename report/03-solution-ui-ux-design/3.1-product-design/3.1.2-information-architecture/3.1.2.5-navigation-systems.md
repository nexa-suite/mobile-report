#### 3.1.2.5 Navigation Systems

La navegación mantiene visible el contexto de la persona, la tarea y el resultado que puede comprobar. Volver conserva un estado seguro y no repite por sí mismo una acción que pudiera duplicar un registro.

| Superficie | Recorrido principal | Regla de continuidad |
| --- | --- | --- |
| Website público | Inicio → producto o solución → detalle → soporte o destino siguiente | Conservar el idioma y el acceso al contenido legal. |
| Operations Mobile | Sesión → contexto autorizado → trabajo → detalle → acción o evidencia → resultado | Volver al último estado seguro y comprobar el contexto antes de mostrar información protegida. |
| Buyer Mobile | Entrega autorizada → transferencia → cantidades → recepción o discrepancia → historial | Mantener separado el resultado del conductor y la recepción del comprador. |

Si vence la sesión o se revoca el contexto, la interfaz retorna al acceso seguro. Si la conexión se interrumpe o una respuesta no llega, el resultado permanece sin confirmar y la persona puede consultar el estado. Un código inválido o vencido detiene la recepción; volver o reintentar no crea otro comprobante, entrega ni discrepancia de manera silenciosa.
