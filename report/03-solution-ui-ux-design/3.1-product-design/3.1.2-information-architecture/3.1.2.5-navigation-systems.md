#### 3.1.2.5. Sistemas de navegación

##### Modelo de navegación

- El Website público usa enlaces agrupados y llamadas a la acción por página.
- Operations Mobile usa una vista inicial limitada por rol, lista de trabajo
  asignado, detalle, paso de comando o evidencia y resultado o historial.
- Buyer Mobile usa una vista de atención de entrega, verificación de handoff,
  receipt e historial de discrepancias.
- Los enlaces profundos y las notificaciones vuelven a comprobar sesión,
  Tenant/Workspace y autorización de Buyer Relationship antes de abrir
  contenido protegido.
- La navegación hacia atrás retorna al último estado seguro; no debe repetir un
  comando.

##### Estados de fallo de navegación

Una sesión expirada, un contexto revocado, una red no disponible, una delivery
desactualizada, un handoff code inválido y un resultado de command desconocido
deben tener destino visible y acción de recuperación. Un retry repite una
solicitud idempotente o muestra el estado no resuelto; no duplica
silenciosamente un receipt, POD o discrepancy.

El diagrama visual de navegación y la revisión en un dispositivo físico no se
incorporan en esta entrega; por ello no se afirma validación de usabilidad o de
comportamiento Mobile.
