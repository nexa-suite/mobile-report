# 3.1.2.5 Navigation Systems

## Navigation model

- Public Website navigation uses grouped links and page-level calls to action.
- Operations Mobile uses a role-limited start view, assigned work list, detail
  view, command/evidence step and result/history.
- Buyer Mobile uses a delivery-attention view, handoff verification, receipt
  and discrepancy history.
- Deep links and notifications always re-check session, Tenant/Workspace and
  Buyer Relationship authorization before opening protected content.
- Back navigation returns to the last safe state; it must not replay a command.

## Navigation failure states

Expired session, revoked context, unavailable network, stale delivery, invalid
handoff code and unknown command result each have a visible destination and
recovery action. A retry repeats an idempotent request or shows the unresolved
state; it does not silently duplicate a receipt, POD or discrepancy.
