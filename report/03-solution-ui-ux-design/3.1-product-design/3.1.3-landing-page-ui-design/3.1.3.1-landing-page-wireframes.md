## Target wireframe specification

| Viewport | Required regions | Responsive rule | Evidence |
| :--- | :--- | :--- | :--- |
| Desktop Web Browser | Header, hero, operational problem, solution areas, proof/limits, CTA, footer | Two-column hero may collapse when content becomes narrow | Wireframe artifact pending |
| Mobile Web Browser | Compact header/drawer, single-column hero, stacked proof, CTA and footer | Preserve reading order, labels and target size | Wireframe artifact pending |

The Website source provides an AS-IS content reference and can be used to
populate these frames after the team approves the information hierarchy. No
Figma/LucidChart link or screenshot is claimed yet.

## Review checklist

- [ ] Desktop and Mobile frames share the same content hierarchy.
- [ ] CTA destination and contact semantics are explicit.
- [ ] Metadata, language and legal links are represented.
- [ ] 320px reflow and keyboard/focus behavior are reviewed.
