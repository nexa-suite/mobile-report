# 3.1.3.2 Landing Page Mock-ups

The current Website pages are an AS-IS visual implementation reference, not a
new academic mock-up package. The final mock-ups must show the approved logo,
token aliases, typography, CTA states, navigation, form validation and
responsive behavior for desktop and Mobile Web Browser.

| Mock-up | Source/status | Required human check |
| :--- | :--- | :--- |
| Desktop Web Browser | Website source; screenshot not attached in this cut | Visual hierarchy, metadata and responsive transition |
| Mobile Web Browser | Website source; screenshot not attached in this cut | 320/390px reflow, touch targets and focus |

No mock-up is marked complete until the image, viewport, source revision and
reviewer are recorded.
