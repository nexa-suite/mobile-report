#### 3.1.3.2 Mock-ups de Landing Page

El Website actual es una referencia visual de implementación pública, no un
nuevo conjunto académico de mock-ups. Los mock-ups que se elaboren deberán
usar el logo aprobado, aliases de tokens, tipografía, estados de CTA,
navegación, validación de formularios y composición responsive.

| Vista | Contenido que debe mostrar | Límite de esta entrega |
| :--- | :--- | :--- |
| Navegador desktop | Jerarquía visual, CTA, metadatos y transición responsive | No se adjunta una imagen de mock-up |
| Navegador Mobile | Reflujo a 320/390 px, objetivos táctiles y foco | No se adjunta una imagen de mock-up |

Una imagen estática no demuestra indexación, despliegue, comportamiento de
formularios ni accesibilidad. Esa evidencia requiere artefactos y pruebas
específicos cuando estén disponibles.
