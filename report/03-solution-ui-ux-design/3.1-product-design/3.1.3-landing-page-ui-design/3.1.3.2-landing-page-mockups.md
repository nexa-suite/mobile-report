# 3.1.3.2 Landing Page Mock-ups

Las páginas actuales de Website son una referencia visual de implementación
AS-IS, no un nuevo paquete académico de mock-ups. Los mock-ups finales deben
mostrar el logo aprobado, aliases de tokens, tipografía, estados CTA,
navegación, validación de formularios y comportamiento responsive para desktop y
Mobile Web Browser.

| Mock-up | Source/status | Required human check |
| :--- | :--- | :--- |
| Desktop Web Browser | Website source; screenshot not attached in this cut | Visual hierarchy, metadata and responsive transition |
| Mobile Web Browser | Website source; screenshot not attached in this cut | 320/390px reflow, touch targets and focus |

Ningún mock-up se marca completo hasta registrar imagen, viewport, revisión del
origen y reviewer.
