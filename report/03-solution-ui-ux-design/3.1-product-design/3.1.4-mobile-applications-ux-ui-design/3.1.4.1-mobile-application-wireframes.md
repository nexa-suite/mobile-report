### 3.1.4 Mobile Applications UX/UI Design

#### 3.1.4.1 Mobile Applications Wireframes

Los wireframes organizan vistas, campos, acciones y estados antes de aplicar el tratamiento visual. El inventario siguiente delimita el contenido que debe verse en los cinco objetivos; no presenta capturas de pantalla como wireframes.

| Objetivo | Vistas y elementos necesarios | Historias relacionadas |
| --- | --- | --- |
| Retomar trabajo autorizado | Acceso, verificación de sesión, selección de contexto y tareas disponibles | MOB-US-001–003 |
| Registrar trabajo de almacén | Tarea asignada, búsqueda o escaneo, ficha de producto y resultado | MOB-US-011–019 |
| Transferir entrega preparada | Resumen de preparación, revisión de asignación, transferencia y aceptación | MOB-US-020–025 |
| Registrar evidencia de entrega | Entrega asignada, intento, resultado, evidencia y estado de envío | MOB-US-026–034 |
| Confirmar recepción del comprador | Entrega propia, verificación del código, cantidades, recepción o discrepancia | MOB-US-044, MOB-US-047–049 |

Los estados vacíos, cargando, error, no autorizado, sin conexión y resultado incierto deben mantener visible el contexto y una salida segura. Operations Mobile y Buyer Mobile son superficies distintas; las vistas de comprador no se atribuyen a Operations Android.
