# 3.1.4.3 Mobile Applications Mock-ups

Mock-ups must express the Design Lab direction without changing the domain
boundary. At minimum, the package must include a session/context state, one
Operations workflow, one delivery/POD state and one Buyer receipt/discrepancy
state for each selected surface.

| Mock-up evidence | Required content | Current state |
| :--- | :--- | :--- |
| Operations Mobile | Warehouse/dispatch/delivery states, touch targets, error and retry | Target specification only |
| Buyer Mobile | Handoff verification, quantities, receipt and discrepancy | Target specification only |
| Responsive/accessibility | Focus, contrast, text spacing, reduced motion and 320/390px behavior | Review pending |

No screen is labeled implemented, validated or accepted until its image/source,
story IDs, viewport, interaction state and reviewer are attached.
