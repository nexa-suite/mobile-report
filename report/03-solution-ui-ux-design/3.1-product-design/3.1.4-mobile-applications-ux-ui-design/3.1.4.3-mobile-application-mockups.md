# 3.1.4.3 Mobile Applications Mock-ups

Los mock-ups deben expresar la dirección de Design Lab sin cambiar el límite de
dominio. Como mínimo, el paquete debe incluir un estado de session/context, un
workflow de Operations, un estado de delivery/POD y un estado de
receipt/discrepancy de Buyer para cada superficie seleccionada.

| Mock-up evidence | Required content | Current state |
| :--- | :--- | :--- |
| Operations Mobile | Warehouse/dispatch/delivery states, touch targets, error and retry | Target specification only |
| Buyer Mobile | Handoff verification, quantities, receipt and discrepancy | Target specification only |
| Responsive/accessibility | Focus, contrast, text spacing, reduced motion and 320/390px behavior | Review pending |

Ninguna pantalla se etiqueta como implemented, validated o accepted hasta
adjuntar su imagen/origen, story IDs, viewport, estado de interacción y
reviewer.
