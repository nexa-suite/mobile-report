#### 3.1.4.3 Mobile Applications Mock-ups

El mosaico de mock-ups muestra pantallas de Nexa Operations para iniciar sesión, abrir el menú de trabajo, buscar por texto o SKU y consultar el producto identificado. Incluye el permiso de cámara con alternativa manual, el escaneo, la confirmación de SKU y una consulta de existencias en modo de solo lectura. En esta última, el mensaje indica que no hay lotes visibles, la confirmación de lote y ubicación está deshabilitada y la identidad de catálogo no confirma cantidades físicas. La lámina documenta el diseño visual de estas vistas. La guía de estilo aplica a ambas superficies, con sus tareas, datos y decisiones separados.

Las capturas de User Flow Diagrams muestran secuencias de pantallas de una aplicación; no se presentan como mock-ups estáticos ni como validación de diseño. El contenido visible debe conservar jerarquía, tamaño de texto, contraste, foco y áreas táctiles de la guía general.

La ficha de cada vista vincula el objetivo de usuario con la historia correspondiente, el actor y el estado que se representa. El estado visual identifica la interacción; el resultado del Driver y la recepción del Buyer conservan significados separados.
