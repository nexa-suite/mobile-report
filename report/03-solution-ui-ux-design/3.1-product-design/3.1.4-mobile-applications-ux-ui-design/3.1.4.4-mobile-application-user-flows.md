#### 3.1.4.4 Mobile Applications User Flow Diagrams

Los flujos distinguen el camino principal y las alternativas que impiden una confirmación incorrecta. Los diagramas expresan comportamiento esperado; las capturas ilustran solo las pantallas visibles en cada secuencia.

**Retomar trabajo autorizado**

```mermaid
flowchart LR
  A[Return to work] --> B{Session can be verified?}
  B -->|Yes| C[Confirm authorized context]
  B -->|Expired or revoked| D[Authenticate again]
  B -->|Unavailable| E[Keep protected work closed]
  D --> C
  C --> F[Open permitted work]
```

![Happy path de acceso y retorno a operaciones](../../../assets/chapter-3/mobile-user-flows/happy-01-session.png)

*La secuencia muestra acceso, verificación visible de sesión y menú de operaciones.*

**Registrar trabajo de almacén**

```mermaid
flowchart LR
  A[Assigned task] --> B{Identify product}
  B -->|Scan| C{Camera permitted?}
  C -->|Yes| D[Read code]
  C -->|No| E[Search manually]
  B -->|Manual search| E
  D --> F{Product verified?}
  E --> F
  F -->|Yes| G[Review product detail]
  F -->|No or ambiguous| E
  G --> H[Return to task]
```

![Happy path de búsqueda con productos similares y fichas](../../../assets/chapter-3/mobile-user-flows/happy-02-search.png)

*La secuencia muestra consultas de texto, resultados con productos similares, apertura de fichas y una nueva consulta.*

**Transferir una entrega preparada**

```mermaid
flowchart LR
  A[Review prepared delivery] --> B{Preparation current?}
  B -->|No| C[Resolve exception]
  B -->|Yes| D[Transfer responsibility]
  D --> E{Transfer confirmed?}
  E -->|Yes| F[Wait for independent driver acceptance]
  E -->|Uncertain| G[Check original transfer]
```

**Registrar evidencia de entrega**

```mermaid
flowchart LR
  A[Open assigned delivery] --> B{Assignment current?}
  B -->|No| C[Refresh or stop]
  B -->|Yes| D[Record actual attempt]
  D --> E{Outcome}
  E -->|Complete or partial| F[Record quantities and available evidence]
  E -->|Absent or rejected| G[Record actual exception]
  F --> H[Check confirmation]
  G --> H
  H -->|Uncertain| I[Check original attempt before retry]
```

**Confirmar recepción del comprador**

```mermaid
flowchart LR
  A[Open own delivery] --> B[Verify transfer code]
  B --> C{Code matches?}
  C -->|No| D[Stop and request review]
  C -->|Yes| E[Compare received quantities]
  E --> F{Quantities match?}
  F -->|Yes| G[Confirm Buyer Receipt]
  F -->|No| H[Record Discrepancy separately]
  G --> I[Check confirmed result]
  H --> I
```

Las secuencias visuales aportadas cubren acceso, identificación de productos y permiso de cámara. Los diagramas de transferencia, entrega y recepción describen los recorridos diseñados para esos objetivos.
