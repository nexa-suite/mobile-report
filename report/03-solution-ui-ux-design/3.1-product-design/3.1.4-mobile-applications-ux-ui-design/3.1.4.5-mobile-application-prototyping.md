#### 3.1.4.5 Mobile Applications Prototyping

El prototipo debe permitir recorrer vistas y decisiones de los cinco objetivos, incluyendo alternativas de cámara denegada, resultado incierto y discrepancia. Cada interacción conserva su estado y la distinción entre Operations Mobile y Buyer Mobile.

El prototipo visual permite revisar secuencia, contenido y recuperación; no demuestra autorización, persistencia, reglas de negocio ni aceptación de producto. La instalación y prueba de la aplicación en un dispositivo físico constituyen una evidencia distinta y requerida para el hito.
