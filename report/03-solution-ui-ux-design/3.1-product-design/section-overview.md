# 3.1 Product Design

The product design section applies a common visual language while preserving
the boundary between the public Website and the planned Mobile surfaces.

| Subsection | Primary source | Current state |
| :--- | :--- | :--- |
| Style Guidelines | Design Lab `v1.0.2`, token JSON and accessibility modes | AS-IS executable evidence; Mobile adoption pending |
| Information Architecture | Website page inventory plus V1 story flows | Web AS-IS and Mobile TARGET |
| Landing Page UI Design | Website HTML/CSS source | Web AS-IS; academic wireframes/mock-ups pending |
| Mobile Applications UX/UI Design | 28 V1 stories, To-Be scenarios and Design Lab direction | TARGET; no rendered Mobile artifact in this cut |

All target artifacts must preserve authorization, connectivity, error and
historical-integrity states from Chapter II. A polished screen without those
states does not satisfy the product requirement.
