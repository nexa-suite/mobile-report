# Capítulo IV: Product Implementation & Validation

## 4.1. Software Configuration Management

### 4.1.1. Software Development Environment Configuration

La configuración reúne las herramientas de planificación, diseño, desarrollo, pruebas, despliegue y control de versiones utilizadas en el proyecto.

Operations Mobile es la aplicación Android nativa desarrollada con Kotlin y Jetpack Compose. Buyer Mobile utiliza Flutter y Dart como aplicación multiplataforma; en este corte se documenta su diseño, sin declarar un build publicado.

Jira organiza el Product Backlog y los Sprints. UXPressia se utilizó para los artefactos de investigación incorporados en el capítulo II. Los servicios REST y las aplicaciones conservan repositorios separados.
