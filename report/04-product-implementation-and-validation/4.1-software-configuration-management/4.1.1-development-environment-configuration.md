## Reproducibility requirements

Cada registro futuro de comando debe incluir directorio de trabajo, comando
exacto, versión de herramienta/runtime, estado de salida, fecha y salida
relevante. No deben committearse secretos, tokens, datos personales ni
información de participantes no aprobada.

El hardware disponible es capacidad para validar, no evidencia de validación.
Este documento no afirma build Mobile, ejecución de containers, ejecución en
dispositivo físico ni llamada a un servicio externo.
