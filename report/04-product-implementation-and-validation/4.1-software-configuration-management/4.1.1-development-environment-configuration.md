# Capítulo IV: Product Implementation & Validation

## 4.1. Software Configuration Management

### 4.1.1. Software Development Environment Configuration

La configuración reúne herramientas para planificación, requisitos, UX/UI,
desarrollo, pruebas, despliegue, documentación y control de versiones. Las
herramientas previstas para clientes Mobile se distinguen de una evidencia de
build, instalación o uso en dispositivo.

| Product / Tool | Purpose | Category / activity | Reference or download URL | Role in Nexa |
| --- | --- | --- | --- | --- |
| Git and GitHub | Controlar versiones, colaboración, revisiones y trazabilidad. | Version Control / Documentation | [GitHub Docs](https://docs.github.com/en) | Conserva el historial de repositorios y contribuciones. |
| GitHub Projects | Organizar Product Backlog, Sprints y Board cuando el equipo publique el registro. | Project Management | [GitHub Projects](https://docs.github.com/en/issues/planning-and-tracking-with-projects) | Soporta priorización y seguimiento de trabajo. |
| Markdown and Pandoc | Redactar el informe modular y generar PDF. | Documentation | [CommonMark](https://spec.commonmark.org/) / [Pandoc](https://pandoc.org/installing.html) | Mantiene el informe académico y su exportación. |
| Figma and UXPressia | Elaborar artefactos de UX/UI, Personas, Journeys, Empathy Maps e Impact Mapping. | Requirements / UX/UI Design | [Figma](https://www.figma.com/) / [UXPressia](https://uxpressia.com/) | Proporciona fuentes de diseño cuando sus exports estén disponibles. |
| Lucidchart, Structurizr and PlantUML | Modelar diagramas de procesos, C4, UML y base de datos. | Requirements / Software Design | [Lucidchart](https://www.lucidchart.com/pages/) / [Structurizr](https://structurizr.com/) / [PlantUML](https://plantuml.com/download) | Documenta diseño estratégico, táctico y arquitectura. |
| Android Studio and Kotlin | Preparar el cliente Native Android. | Software Development / Testing | [Android Studio](https://developer.android.com/studio) | Soporta la evaluación de flujo Android y recurso interno del dispositivo. |
| Flutter and Dart | Evaluar y construir el cliente Cross-Platform cuando el equipo confirme la alternativa. | Software Development / Testing | [Flutter](https://docs.flutter.dev/install) | Soporta paridad de experiencia y contratos, sin redefinir la autoridad del servidor. |
| Java, Spring Boot, PostgreSQL and OpenAPI | Mantener servicios RESTful y contratos de negocio. | Software Development / Testing / Services Documentation | [Spring Boot](https://spring.io/projects/spring-boot) / [PostgreSQL](https://www.postgresql.org/download/) / [OpenAPI](https://spec.openapis.org/oas/latest.html) | Provee contratos, persistencia y documentación para clientes autorizados. |
| HTML5, CSS3 and JavaScript | Construir la Landing Page estática. | Software Development / Deployment | [MDN Web Docs](https://developer.mozilla.org/) | Presenta modelo de negocio, CTA, contacto y enlaces legales. |
