## Required deployment record

Before calling a deployment complete, record the source SHA, build command,
artifact checksum, configuration contract, secret handling, service versions,
database migration state, URL or distribution channel, installation device,
observed result and rollback path. Do not commit secrets or treat a local
Docker installation as cloud readiness.

The C4 deployment target and its limitations are described in
[2.5.3.4 Deployment Diagrams](../../02-requirements-and-software-solution-design/2.5-strategic-level-domain-driven-design/2.5.3-software-architecture/2.5.3.4-deployment-diagrams.md).

The local observation is documented in the
[live baseline](../../../delivery-checklists/live-baseline.md) and the
[implementation evidence register](../../../delivery-checklists/implementation-evidence-register.md).
It is a local validation environment only: it does not establish cloud
deployment, distribution, physical-device installation or production
readiness.
