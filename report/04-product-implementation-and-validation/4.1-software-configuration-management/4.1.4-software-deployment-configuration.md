### 4.1.4. Software Deployment Configuration

La configuración de despliegue debe respetar la vista C4 y separar las
superficies públicas, los servicios de negocio y las aplicaciones Mobile.

| Superficie | Configuración que debe existir antes de declarar despliegue | Límite de esta entrega |
| :--- | :--- | :--- |
| Website | Host público, configuración de dominio, contenido estático, metadatos y enlaces legales | No se declara publicación o medición de conversión |
| API | Configuración de Spring Boot, PostgreSQL, almacenamiento compatible con S3, migraciones, secretos, observabilidad y rollback | No se declara un entorno cloud listo para producción |
| Operations Mobile | Build identificable, configuración de endpoint, permisos, canal de distribución y resultado de instalación | No se adjunta build ni prueba en dispositivo |
| Buyer Mobile | Build identificable, configuración de endpoint, permisos, canal de distribución y resultado de instalación | No se adjunta build ni prueba en dispositivo |

El diagrama de despliegue C4 del Capítulo II guía estas dependencias. Una
instalación local, un emulador, una rama de código o un enlace de prototipo no
equivalen por sí solos a un despliegue distribuido ni a preparación para
producción.
