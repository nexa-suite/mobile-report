### 4.1.4. Software Deployment Configuration

La configuración de despliegue preserva la separación entre Landing Page,
servicios y aplicaciones Mobile. Cada producto requiere un artefacto
identificable, configuración sin secretos y evidencia de resultado antes de
declarar su publicación. El despliegue, la instalación Mobile y la evidencia de
dispositivo son **NOT YET DUE** para este hito.

*Configuración y evidencia requeridas antes de declarar un despliegue.*

| Product | Source-to-deployment configuration | Evidence required |
| --- | --- | --- |
| Landing Page | Construir contenido estático desde el repositorio Website, configurar host, dominio, metadatos, enlaces legales y rollback. | URL pública, commit, fecha, captura responsive y resultado observado. |
| Web Services | Construir desde API, aplicar migraciones, configurar PostgreSQL, Object Storage, secretos, OpenAPI, observabilidad y rollback. | Artefacto, endpoint documentado, entorno, pruebas y resultado observado. |
| Operations Mobile | Generar build identificable, configurar endpoint, permisos, firma y canal de distribución. | Build, dispositivo o emulador, flujo ejecutado y resultado observado. |
| Buyer Mobile | Generar build identificable, configurar endpoint, permisos, firma y canal de distribución. | Build, dispositivo o emulador, flujo ejecutado y resultado observado. |

*Nota.* La tabla define requisitos futuros de despliegue; ningún artefacto,
URL, build o resultado de producción se presenta como existente.

El Deployment Diagram del Capítulo II explica la relación entre estas
superficies. Una rama, una configuración local o un enlace de prototipo no
equivale por sí solo a despliegue.
