#### 4.2.1.6. Execution Evidence for Sprint Review

La evidencia de ejecución del Sprint 1 comprende comprobaciones
de servicios realizadas en un entorno aislado de Nexa API y
una verificación inicial de Operations Mobile mediante un
emulador Android.

Las comprobaciones del API permitieron observar respuestas
relacionadas con la autenticación, la gestión de sesiones y
la resolución de identificadores de productos. Por su parte,
la ejecución en el emulador permitió verificar la instalación
y el inicio de la aplicación sin una sesión activa.

Ambos resultados se presentan por separado, debido a que
corresponden a componentes distintos y no constituyen
una demostración completa de la integración entre la
aplicación móvil y los servicios del sistema.

*Operaciones observadas en el fixture aislado*

| Observed operation | Existing result | Scope relation | Limit |
| --- | --- | --- | --- |
| `POST /api/v1/authentication/sign-in` | HTTP 200 | `MOB-US-001`; `TS-MOB-001` | Fixture aislado; no Android en vivo ni entorno desplegado. |
| `GET /api/v1/session` | HTTP 200, `surface=PLATFORM`, usuario y Workspace presentes | `MOB-US-002`, `MOB-US-003` | Contexto observado del fixture; no prueba autorización productiva. |
| `POST /api/v1/authentication/refresh` | HTTP 200 y header refresh de reemplazo | `MOB-US-001` | Fixture aislado; no prueba ciclo de vida real de dispositivo. |
| `POST /api/v1/authentication/sign-out` | HTTP 204 | `MOB-US-001` | Fixture aislado; no prueba sesión de producción. |
| `GET /api/v1/skus/resolve?identifier=PROD-0001` | HTTP 200, `RESOLVED` con candidata seleccionada por servidor | `MOB-US-011`; `TS-MOB-007` | No prueba cámara ni lectura física. |
| `GET /api/v1/skus/resolve?identifier=UNKNOWN-MOBILE-AV1` | HTTP 200, `NOT_FOUND` sin candidatas | `MOB-US-011`; `TS-MOB-007` | El fixture no aportó una corrida ambigua fija. |

**EMULATOR.** El registro existente del 2026-09-02 para `Nexa_AV1_API36`
indica PASS para instalación, launch y pantalla de acceso bloqueada sin sesión
activa:

```text
android emulator start --cold Nexa_AV1_API36
android install --device emulator-5554 --apks=operations/build/outputs/apk/debug/operations-debug.apk
android run --device emulator-5554 --apks=operations/build/outputs/apk/debug/operations-debug.apk --activity=com.nexa.mobile.operations.MainActivity
android layout --device emulator-5554 --pretty
```

Los resultados obtenidos permiten comprobar el comportamiento
de determinadas operaciones del API bajo condiciones
controladas. La consulta de sesión registrada utilizó
la superficie PLATFORM, por lo que esta evidencia no
demuestra que el mismo recorrido se haya ejecutado
desde Operations Mobile.

La prueba realizada en el emulador permitió verificar
el inicio de la aplicación y su comportamiento ante
la ausencia de una sesión activa. Sin embargo, no incluyó
una sesión conectada al API publicado ni la identificación
de productos mediante la cámara del dispositivo.

Las comprobaciones y capturas obtenidas posteriormente
en un dispositivo físico se presentan en la sección
4.2.2.6, correspondiente al Sprint 2. De esta manera,
se conserva la evolución del desarrollo sin atribuir
al primer sprint resultados obtenidos en etapas posteriores.
Estas evidencias representan verificaciones técnicas
específicas y no sustituyen la aceptación funcional de
las historias de usuario.
