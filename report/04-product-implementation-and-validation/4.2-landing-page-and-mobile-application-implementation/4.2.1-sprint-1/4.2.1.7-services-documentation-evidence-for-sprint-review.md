#### 4.2.1.7. Services Documentation Evidence for Sprint Review

Los contratos observados se documentan como evidencia read-only del API
`v0.17.0`. El servidor conserva autoridad sobre identidad, sesión, Tenant,
Workspace, permisos y resolución SKU. Esta tabla no inventa endpoints ni
declara un servicio desplegado.

| Observed endpoint | Contract observation | Sprint 1 relation | Evidence boundary |
| --- | --- | --- | --- |
| `POST /api/v1/authentication/sign-in` | Recibe `identifier`, `password`, `workspaceSlug` y `surface`; el transporte nativo usa `ClientSurface.PLATFORM` y `X-Nexa-Client: NATIVE`. La respuesta observada es HTTP 200 con access token, expiración y sesión. | `MOB-US-001`; `TS-MOB-001` | **LOCAL FIXTURE ONLY** para runtime; no prueba Android contra API desplegada. |
| `POST /api/v1/authentication/refresh` | Usa token refresh y marker de superficie; HTTP 200 observado con header refresh de reemplazo. Un refresh fallido invalida la sesión local. | `MOB-US-001`; `TS-MOB-001` | **LOCAL FIXTURE ONLY**; no prueba almacenamiento o rotación en hardware. |
| `POST /api/v1/authentication/sign-out` | Usa bearer y superficie; no body; HTTP 204 observado. | `MOB-US-001`; `TS-MOB-001` | **LOCAL FIXTURE ONLY**; no prueba una sesión de producción. |
| `GET /api/v1/session` | Requiere bearer; HTTP 200 observado con user, tenant, workspace, membership y surface. | `MOB-US-002`, `MOB-US-003`; `TS-MOB-001` | Contexto confirmado por servidor en fixture; no prueba autorización de producción. |
| `GET /api/v1/skus/resolve?identifier=<value>` | Requiere bearer y visibilidad Tenant/Workspace; conserva `RESOLVED`, `NOT_FOUND` o `AMBIGUOUS`. Una respuesta ambigua no selecciona `skuId`. | `MOB-US-011`; `TS-MOB-007` | **LOCAL FIXTURE ONLY** para `RESOLVED` y `NOT_FOUND`; no prueba cámara. |

El native sign-in no llama al workspace-preview público: ese route queda fuera
del flujo nativo observado. No se reclama ningún endpoint adicional. La cámara
sólo captura y decodifica; no crea selección SKU, recepción, picking ni otro
hecho de negocio.
