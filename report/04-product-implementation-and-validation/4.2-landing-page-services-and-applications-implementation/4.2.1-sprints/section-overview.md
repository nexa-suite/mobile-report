# 4.2.1 Sprints

Each Sprint contains the nine evidence categories required by the rubric. The
canonical academic delivery has three Sprints: Sprint 1 for TB1, Sprint 2 for
AV2 and Sprint 3 for TB2. The folders are prepared, but dates, owners, board
links, execution output and review results remain pending so that no velocity
or completion is fabricated.

| Sprint | Intended academic focus | Candidate stories | Evidence state |
| :--- | :--- | :--- | :--- |
| Sprint 1 | Safe access, context and warehouse identification/receiving | MOB-US-001..017, MOB-US-019 | Template only; owner and execution pending |
| Sprint 2 | Dispatch preparation, handoff and driver delivery execution | MOB-US-020..034 | Template only; owner and execution pending |
| Sprint 3 | Buyer attention, handoff verification, receipt and discrepancy | MOB-US-044, MOB-US-047..049 | Template only; owner and execution pending |

For each canonical sprint, complete the corresponding files for planning, backlog,
leaders/collaborators, development, execution, service documentation,
deployment, testing and collaboration insights. Each entry must cite the
actual issue/task, commit or review link and validation command/capture.
