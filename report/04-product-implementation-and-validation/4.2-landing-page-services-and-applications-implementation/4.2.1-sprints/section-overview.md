# 4.2.1 Sprints

Cada Sprint contiene las nueve categorías de evidencia requeridas por la
rúbrica. La entrega académica tiene tres Sprints: Sprint 1 para TB1, Sprint 2
para AV2 y Sprint 3 para TB2. Las carpetas están preparadas, pero fechas,
owners, enlaces del board, salida de ejecución y resultados de revisión siguen
pendientes para no fabricar velocidad ni completitud.

| Sprint | Intended academic focus | Candidate stories | Evidence state |
| :--- | :--- | :--- | :--- |
| Sprint 1 | Safe access, context and warehouse identification/receiving | MOB-US-001..017, MOB-US-019 | Template only; owner and execution pending |
| Sprint 2 | Dispatch preparation, handoff and driver delivery execution | MOB-US-020..034 | Template only; owner and execution pending |
| Sprint 3 | Buyer attention, handoff verification, receipt and discrepancy | MOB-US-044, MOB-US-047..049 | Template only; owner and execution pending |

Para cada Sprint, completa los archivos correspondientes de planificación,
backlog, leaders/collaborators, desarrollo, ejecución, documentación de
servicios, deployment, testing y collaboration insights. Cada entrada debe
citar el issue/task real, commit o enlace de revisión y comando/captura de
validación.
