# 4.3.3 Evaluations According to Heuristics

## Evaluation register

El equipo debe aplicar el formato del Anexo E de la rúbrica al artefacto real y
registrar evaluator, fecha, viewport/dispositivo, heurística, evidencia,
severidad, historia afectada, recomendación y resultado de la re-revisión.

| Artifact | Review dimensions | Evidence state |
| :--- | :--- | :--- |
| Website landing page | Usability, information architecture, responsive behavior, language and accessibility | Source exists; report capture/evaluator pending |
| Operations Mobile target | Role clarity, physical workflow, error/retry, touch and accessibility | No rendered artifact to evaluate |
| Buyer Mobile target | Handoff, receipt/discrepancy, trust, status and recovery | No rendered artifact to evaluate |

No se reporta puntuación heurística ni total de severidad hasta que un evaluator
haya inspeccionado realmente el artefacto. Un token de diseño o checklist no es
un hallazgo.
