# Anexo F: Terminology and communication

Convenciones compactas para comunicación técnica y académica de Nexa. Este
anexo no reemplaza el Ubiquitous Language ni el Glossary del informe.

| Concept | Preferred usage |
| --- | --- |
| Library | Biblioteca. |
| Requirement | Requisito. |
| Request | Solicitud, petición o requerimiento según el contexto; no usar `requisito` como traducción de `request`. |
| Application | Aplicación. |
| Deploy / Deployment | Desplegar / despliegue. |
| Test / Testing | Prueba / pruebas, según el contexto. |
| Elicit | Obtener / recabar. |
| Scrum | Framework o marco de trabajo; no metodología. |
| Commit | Crear o registrar un commit; no `commitear` ni `comitear`. |
| UI element or report structure | Usar view, section, dialog, toolbar, sidebar, capítulo, anexo, cuadro o tabla cuando corresponda; evitar `apartado` como término genérico. |

En comunicación oral y escrita se evitan las mutaciones `deployar`, `testear`,
`commitear` y `comitear`. Los términos originales en inglés se conservan cuando
son nombres establecidos de una herramienta, API, patrón o artefacto.
