# Software Engineering Methods and Techniques

## Fuentes clasificadas

| Referencia | Técnica o enfoque | Aplicación documentada |
| :--- | :--- | :--- |
| [M1](../../92-bibliography/bibliography.md) | Investigación, decisiones de diseño, prototipado y UX de una aplicación móvil | Sustenta el registro de decisiones, wireflows y prototipo; no convierte un mockup en validación |
| [M2](../../92-bibliography/bibliography.md) | Evaluación de usabilidad con métodos complementarios | Sustenta el plan de entrevistas, tareas/escenarios e inspección heurística; no reemplaza participantes reales |
| Blueprint DDD/C4 | Modelado de dominio y arquitectura | Fuente de producto/arquitectura del proyecto, no paper Q1/Q2 ni evidencia de ejecución del workshop |

El informe conserva la diferencia entre técnica aplicada, fuente de sustento y
resultado observado. Un método descrito no prueba que la sesión, evaluación o
decisión haya ocurrido; esa evidencia requiere fecha, participantes, artefacto,
responsable y revisión humana.
